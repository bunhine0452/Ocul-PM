Ocul 4.0 이후의 화면은 다섯 화면(오늘 · 작업 일지 · 계획 · 변경 · 터미널)과 설정입니다. 원칙은 하나 — **예외만 보여 준다.** 화면의 크기는 에이전트가 한 양이 아니라 사람이 볼 것에 비례하고, 하루 3건 쓰는 사람과 60건 쓰는 사람이 모드 없이 같은 화면을 씁니다. 에이전트는 앱 안 **터미널** 탭에서 돌려도 되고, 여러분의 터미널에서 돌려도 됩니다 — 기록은 똑같이 남습니다.

윗줄 탭 순서 = `⌘` 번호 순서입니다 (`⌘1` ~ `⌘5`). `⌃Tab` · `⌃⇧Tab` 으로 차례로 돌고, 트랙패드 두 손가락 쓸기로 뒤로 · 앞으로 갑니다. 설정은 윗줄 끝의 톱니(`⌘,`)입니다. 처음 켜면 「처음 쓰는 법」 네 쪽이 이 화면들을 짧게 보여 주고, 도움말 메뉴와 `⌘K` 에서 다시 엽니다.

| 화면 | 키 | 하는 일 |
|---|---|---|
| **오늘** | `⌘1` | 「먼저 볼 것」 — Claude 가 기다려요 · Claude 가 물어요(그 자리에서 답) · 판정 실패 · 일지 없는 변경 · 막힘 · 플러그인 새 판. 그 아래 검증 없이 끝난 일지와 오늘 한 일(증거가 선 일은 계획별로 한 줄) |
| **작업 일지** | `⌘2` | 왼쪽 목록 + 오른쪽 상세(본문부터 — 검증 상자 · 파일별 인라인 diff · 관련 일지). 머리의 계획 항목은 그 항목으로 가는 링크. 일지 검색(`/`)이 여기 삽니다 |
| **계획** | `⌘3` | 제목 바로 아래 완료 조건 · 확인 명령 · 마지막 판정, 다음 할 일을 터미널에서 실행하거나 끝까지(`/goal`). 항목마다 「Claude 에게 보내기」. 끝난 단계는 한 줄로 접힘 |
| **변경** | `⌘4` | 커밋 전 / 최근 커밋의 diff. 「일지 없음」(어느 일지에도 없는 파일)이 먼저, [Claude 에게 맡기기]로 기록을 부탁 |
| **터미널** | `⌘5` | 이 프로젝트 폴더의 셸. 세션이 하나면 터미널만, 둘 이상이면 위에 탭 줄. Claude Code 의 상태 신호로 일하는 중 · 기다림 · 끝남을 압니다. 오늘 · 계획의 「다음」 이 여기서 `claude` 를 엽니다. 세션은 창을 닫으면 끝나고, 무언가 도는 중이면 먼저 묻습니다 |
| **설정** | `⌘,` | 에이전트 연결 · 이 프로젝트 · 표시 · 데이터, 한 쪽 |

프로젝트가 없는 창은 **시작 창**입니다 — 최근 프로젝트와 폴더 열기. 폴더를 고르면 그 창이 그 프로젝트가 됩니다.

일지와 계획은 이 앱의 두 기둥입니다 — 각각 [작업 일지](/wiki/journal)와 [계획](/wiki/planner)에서 자세히 다룹니다.

:::tip
일지 상세와 변경 화면의 「열기」는 설정의 **외부 편집기** 명령(VS Code · Cursor …)으로 그 파일을 엽니다. 앱 안 편집기는 없습니다.
:::

## 4.0 에서 걷은 화면

| 걷은 것 | 대신 |
|---|---|
| 검색(의미 · 심볼 · 텍스트) | 일지 검색은 작업 일지(`/`), 코드 검색은 에이전트의 grep |
| 문제 해결(논의) | 계획의 `## 결정` 블록. `.oculpm/discussion/` 파일은 지우지 않습니다 |
| 브랜치 · 스킬·규칙 | 기록률은 오늘 · 변경의 「기록 없음」, 스킬은 플러그인 |
| 메뉴바 트레이 · 크롬식 탭 | 창 하나 = 프로젝트 하나, OS 의 창 전환 |
| 간단 / 전문 밀도 | 예외만 보여 주는 한 화면 |

근거(실측)는 저장소의 [PROMISE.md](https://github.com/bunhine0452/Ocul-PM/blob/main/docs/PROMISE.md) 「4.0 에서 걷은 것」 표에 있습니다.
