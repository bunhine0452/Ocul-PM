## 설치

1. [GitHub Releases](https://github.com/bunhine0452/Ocul-PM/releases/latest) 에서 `.dmg` 를 받아 응용 프로그램에 넣습니다. macOS (Apple Silicon) 전용입니다.
2. 처음 열 때 macOS 가 확인 창을 띄우면 「열기」를 누릅니다.
3. 이후 버전은 앱 안에서 자동으로 업데이트됩니다 (설정 → 업데이트에서 수동 확인도 가능).

계정을 만들 필요가 없습니다 — 앱을 열면 바로 시작 화면입니다.

## 프로젝트 추가와 추적 시작

시작 화면에서 **기존 폴더 불러오기**로 코드가 있는 폴더를 고르면 그 프로젝트의 추적이 시작됩니다. 이때 프로젝트 안에 두 가지가 생깁니다:

- `.oculpm/` — 일지·계획·토의가 쌓이는 폴더 (전부 마크다운)
- `AGENTS.md` — 에이전트에게 "작업을 마치면 일지를 남겨라"라고 알려 주는 기록 규칙

:::note
`AGENTS.md` 는 Claude Code·Codex CLI·Gemini CLI 등 대부분의 에이전트가 네이티브로 읽는 파일입니다. 이 파일이 있는 프로젝트에서 에이전트가 일하면, 별도 설정 없이도 일지를 남기기 시작합니다.
:::

## 첫 일지 확인

에이전트에게 아무 작업이나 시켜 보세요 — 앱 안의 Claude Code 화면에서든, 터미널에서든. 작업이 끝나면:

- **작업 일지** 화면(⌘2)에 새 일지가 뜨고
- **오늘 현황**(⌘1)의 흐름에 잡히고
- **변경 diff**(⌘5)에서 그 변경을 줄 단위로 확인할 수 있습니다

일지가 안 쌓인다면 [문제 해결](/wiki/troubleshooting)의 첫 항목을 보세요.
