## 설치

1. [GitHub Releases](https://github.com/bunhine0452/Ocul-PM/releases/latest) 에서 OS 에 맞는 파일을 받습니다 — macOS(Apple Silicon) `.dmg`, 베타인 Windows x64 · Linux x64.
2. macOS 빌드는 Apple Developer ID 로 서명하고 공증(notarization)까지 마쳐 **경고 없이 열립니다**. 인터넷에서 받은 앱임을 알리는 확인 창이 한 번 뜨면 「열기」를 누릅니다.
3. 이후 버전은 앱 안에서 자동으로 업데이트됩니다 (설정 → 데이터 → 「업데이트 확인」으로 수동 확인도 됩니다).

계정을 만들 필요가 없습니다 — 앱을 열면 바로 **시작 창**입니다.

## 폴더 고르기와 기록 켜기

처음 켜면 「처음 쓰는 법」 네 쪽(하는 일 · 다섯 화면 · 에이전트 연결 · 손에 익히기)이 뜹니다. 닫으면 시작 창 — 최근 프로젝트와 **폴더 열기**입니다. 폴더를 고르고 기록을 켜면 프로젝트 안에 두 가지가 생깁니다:

- `.oculpm/` — 일지 · 계획이 쌓이는 폴더 (전부 마크다운)
- `AGENTS.md` — 에이전트에게 "작업을 마치면 일지를 남겨라 · 판정은 네가 아닌 것이"라고 알려 주는 기록 규칙

시작 창에서 프로젝트를 고르면 **그 창이 곧 그 프로젝트**가 됩니다 (창 하나 = 프로젝트 하나).

:::note
`AGENTS.md` 는 Claude Code · Codex · Gemini CLI 등 대부분의 에이전트가 네이티브로 읽는 파일입니다. 이 파일이 있는 프로젝트에서 에이전트가 일하면, 별도 설정 없이도 일지를 남기기 시작합니다.
:::

## 첫 일지 확인

터미널의 에이전트에게 아무 작업이나 시켜 보세요. 작업이 끝나면 몇 초 안에:

- **작업 일지**(⌘2)에 새 일지가 뜨고
- **오늘**(⌘1)의 「오늘 한 일」에 잡히고 — 검증 칸에 명령 증거가 없으면 「검증 없이 끝난 일지」에 섭니다
- **변경**(⌘4)에서 그 변경을 줄 단위로 확인할 수 있습니다

일지가 안 쌓인다면 [문제 해결](/wiki/troubleshooting)의 첫 항목을 보세요.
