`⌘,` 로 엽니다. 4.0 의 설정은 **한 쪽**입니다 — 3.x 의 탭 열둘(LLM · 인덱싱 · 자동화 · 진단 …)은 그 기능과 함께 걷었습니다. 맨 위의 **「고칠 것 N」** 한 줄이 손댈 것(플러그인이 없거나 옛 판 · 규칙 파일이 뒤처짐 · 앱 새 판 …)을 모아 말하고, 누르면 그 칸으로 갑니다. 고칠 것이 없으면 그 줄은 없습니다.

| 칸 | 무엇 |
|---|---|
| **에이전트** | Claude Code 플러그인이 깔렸는지, 이 프로젝트에 정말 붙었는지(꺼짐 · 다른 프로젝트에만 · 앱을 못 찾음)와 「일지가 안 와요」 진단, Cursor · Gemini CLI 기록 도구 등록, 깔린 판이 앱보다 낮은지. 설치 · 업데이트 명령을 복사합니다. **Claude Code 테마** 줄은 Claude Code 의 화면 색을 Ocul 터미널에 맞추는 파일(`~/.claude/themes/ocul.json`)을 앱이 관리하는 자리이고, 고르는 것은 Claude 안의 `/theme` 입니다. Codex 줄은 Codex 가 깔린 기기에만 서고, 「MCP 직접 등록」 은 플러그인 없이 쓰거나 플러그인이 4.12 보다 옛 판일 때의 우회로입니다(4.12 부터는 Windows 에서도 플러그인의 MCP 가 뜨니, 둘 다 켜면 도구가 두 벌 보입니다). 칸 머리의 「다시 확인」 이 다시 묻습니다. Cursor · Gemini CLI 는 규칙 파일(`AGENTS.md`)만으로 기록하니 따로 연결할 것이 없습니다 |
| **이 프로젝트** | 규칙 파일(`AGENTS.md`)의 판(새 판이면 「올리기」, 기록이 꺼져 있으면 「기록 켜기」), `.oculpm` 폴더의 위치, 캐시 「처음부터 다시 만들기」(이 프로젝트의 캐시를 폴더의 일지에서 다시 만듭니다) |
| **모양** | 테마(시스템 · 라이트 · 다크), 글자 크기, 앱 아이콘(macOS) |
| **앱** | 언어(한국어 · English), 잠자기 막기(Claude 가 일하는 동안만), 파일 열기(자동 · VS Code · Cursor · 기본 앱 · 직접 입력), 업데이트(앱 판과 「업데이트 확인」), 로그 폴더, 캐시 크기와 「정리하기」 |

## 앱 안 AI 는 없습니다

4.0 의 앱은 LLM 을 부르지 않습니다 — API 키 · 모델 · 폴백 설정이 없습니다. 요약이나 보고서는 터미널의 에이전트에게 시키고, 에이전트는 MCP 도구(`journal_search` · `journal_read`)로 쌓인 일지를 읽습니다. 3.x 가 키체인에 남긴 API 키 항목은 앱이 더 읽지도 지우지도 않습니다.

## 업데이트

평소에는 앱이 알아서 확인하고, 새 판이 있으면 업데이트 알림이 섭니다. 앱 칸의 업데이트 줄에서 「업데이트 확인」으로 수동 확인하고, 새 판이 있으면 「설치하고 다시 시작」을 누릅니다. Linux deb 로 설치했다면 앱 안 업데이트 대신 릴리스 페이지에서 새 `.deb` 를 받습니다. 최신 릴리스에 이 OS 용 빌드가 없으면 「이 OS 의 새 판이 아직 없어요」 라고 말합니다 — 오류가 아닙니다.
