`⌘,` 로 엽니다. 4.0 의 설정은 **한 쪽**입니다 — 3.x 의 탭 열둘(LLM · 인덱싱 · 자동화 · 진단 …)은 그 기능과 함께 걷었습니다.

| 칸 | 무엇 |
|---|---|
| **에이전트 연결** | Claude Code 플러그인 · Codex 가 깔렸는지, 깔린 판이 앱보다 낮은지. 설치 · 업데이트 명령을 복사합니다. Cursor · Gemini CLI 는 규칙 파일(`AGENTS.md`)만으로 기록하니 따로 연결할 것이 없습니다 |
| **이 프로젝트** | 규칙 파일의 판(새 판이면 「올리기」), 기록이 꺼져 있으면 「기록 켜기」, 프로젝트 폴더 위치 |
| **표시** | 언어(한국어 · English), 밝기(시스템 · 밝게 · 어둡게), 글자 크기 |
| **데이터** | 캐시 크기와 「정리해서 돌려받기」, 「처음부터 다시 만들기」(이 프로젝트의 캐시를 일지 파일에서 다시 만듭니다), 앱 판 · 업데이트 확인, 로그 폴더 |

## 앱 안 AI 는 없습니다

4.0 의 앱은 LLM 을 부르지 않습니다 — API 키 · 모델 · 폴백 설정이 없습니다. 요약이나 보고서는 터미널의 에이전트에게 시키고, 에이전트는 MCP 도구(`journal_search` · `journal_read`)로 쌓인 일지를 읽습니다. 3.x 가 키체인에 남긴 API 키 항목은 앱이 더 읽지도 지우지도 않습니다.

## 업데이트

평소에는 앱이 알아서 확인합니다. 데이터 칸의 「업데이트 확인」으로 수동 확인하고, 새 판이 있으면 「설치하고 다시 시작」을 누릅니다. Linux deb 로 설치했다면 앱 안 업데이트 대신 릴리스 페이지에서 새 `.deb` 를 받습니다. 최신 릴리스에 이 OS 용 빌드가 없으면 「이 OS 의 새 판이 아직 없어요」 라고 말합니다 — 오류가 아닙니다.
