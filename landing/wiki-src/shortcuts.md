`⌘` 번호는 사이드바 순서에서 자동으로 나옵니다 — 각 화면이 무엇을 하는지는 [화면 둘러보기](/wiki/screens)에. Windows · Linux 에서는 `⌘` 대신 `Ctrl` 입니다.

## 어디서나

| 키 | 동작 |
|---|---|
| `⌘K` | 커맨드 팔레트 — 화면 · 프로젝트 · 일지 · 계획을 제목으로 찾아 바로 엽니다 |
| `⌘1` ~ `⌘4` | 화면 바로가기 — `⌘1` 오늘 · `⌘2` 작업 일지 · `⌘3` 계획 · `⌘4` 변경 |
| `⌘,` | 설정 |
| `⌘[` / `⌘]` | 화면 뒤로 / 앞으로 — 브라우저처럼, 방금 보던 화면으로 |
| `⌘/` | 단축키 치트시트 |

## 창

창 하나가 프로젝트 하나입니다 — 탭은 없습니다.

| 키 | 동작 |
|---|---|
| `⌘O` | 최근 프로젝트 — 이미 열린 프로젝트면 그 창이 앞으로 옵니다 |
| `⇧⌘N` | 새 창 (시작 창) |
| `⌘W` | 창 닫기 — macOS 는 마지막 창을 닫아도 앱이 남고, 독을 누르면 다시 열립니다 |

## 오늘 · 작업 일지

키는 그 화면 안에서만 듣습니다.

| 키 | 동작 |
|---|---|
| `j` / `k` | 아래 / 위 항목 |
| `Enter` | 그 항목의 기본 동작 (diff 보기 · 계획 열기 …) |
| `v` | 오늘 — 확인함 |
| `c` | 오늘 — 다음 항목 프롬프트를 클립보드로 |
| `/` | 작업 일지 — 일지 검색 |

:::note
앱 안 터미널 · 편집기 · 에이전트 화면은 2026-10-28 에 걷었습니다. 에이전트는 여러분의 터미널에서 돌고, 계획 화면의 [프롬프트 복사] · [until-done 으로 복사]와 오늘 화면의 `c` 가 프롬프트를 **클립보드**에 담아 줍니다.
:::
