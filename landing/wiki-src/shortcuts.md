`⌘` 번호는 윗줄 탭 순서에서 자동으로 나옵니다 — 각 화면이 무엇을 하는지는 [화면 둘러보기](/wiki/screens)에. Windows · Linux 에서는 `⌘` 대신 `Ctrl` 입니다. 앱에서 `⌘/` 를 누르면 전체 표가 뜹니다 — 계획 · 변경 화면 안의 키도 거기 있습니다.

## 어디서나

| 키 | 동작 |
|---|---|
| `⌘K` | 커맨드 팔레트 — 터미널 세션(기다림 먼저) · 화면 · 동작(단축키 전체 · 폴더 열기 · 편집기에서 열기 · 프로젝트 색 …) · 프로젝트 · 계획 · 일지를 찾아 바로 엽니다. 초성으로도 찾습니다(`ㅇㅈ` → 작업 일지) |
| `⌘J` | 기다리는 세션으로 — 가장 오래 기다린 세션부터, 다시 누르면 다음. 이 창에 없으면 기다림이 있는 다른 프로젝트 창을 앞으로 가져옵니다 (터미널 안에서 Windows · Linux 는 `Ctrl+Shift+J`) |
| `⌘1` ~ `⌘5` | 화면 바로가기 — `⌘1` 오늘 · `⌘2` 작업 일지 · `⌘3` 계획 · `⌘4` 변경 · `⌘5` 터미널 |
| `⌘,` | 설정 |
| `⌘[` / `⌘]` | 화면 뒤로 / 앞으로 — 브라우저처럼, 방금 보던 화면으로 |
| `⌘/` | 단축키 치트시트 |
| `?` | 이 화면의 키 — 지금 화면의 키만 작은 시트로 (글자를 받는 칸 · 터미널 안에서는 글자 그대로). 한 번 더 누르면 닫히고, 「단축키 전체」 로 전체 표가 열립니다 |
| `⇧⌘C` | 영수증 복사 — 오늘 · 일지 상세 · 변경 화면에서 (Windows · Linux 는 `Ctrl+Shift+C`). 일지 상세에서는 그 일지 한 건 |
| `⌃Tab` / `⌃⇧Tab` | 다음 / 이전 화면 (차례로 돕니다) |
| 두 손가락 쓸기 | 화면 뒤로 / 앞으로 (트랙패드) |

## 창

창 하나가 프로젝트 하나입니다 — 탭은 없습니다.

| 키 | 동작 |
|---|---|
| `⌘O` | 최근 프로젝트 — 쳐서 거르고, 이미 열린 프로젝트면 그 창이 앞으로 옵니다 |
| `⇧⌘N` | 새 창 (시작 창) |
| `⌘W` | 창 닫기 — 터미널에 세션이 여럿이면 고른 세션부터. macOS 는 마지막 창을 닫아도 앱이 남고, 독을 누르면 다시 열립니다 |
| `⌥Tab` | 최근 창으로 — 톡 누르면 직전 창, 누르고 있으면 최근 순 목록 (Windows · Linux 는 Ctrl+백틱) |
| `⌥⌘1` ~ `⌥⌘9` | 최근 순 프로젝트 창으로 — 목록을 열지 않고. 지금 창에는 번호가 없습니다 (Windows · Linux 는 `Alt+1` ~ `Alt+9`) |

## 오늘 · 작업 일지

키는 그 화면 안에서만 듣습니다.

| 키 | 동작 |
|---|---|
| `j` / `k` | 아래 / 위 항목 |
| `Enter` | 오늘 — 그 줄의 첫 단추(다시 확인 · 계획 열기 · 변경 보기 …, 질문은 답 칸으로) · 작업 일지 — 상세로 |
| `v` | 읽음 표시 — 오늘은 검증 없는 일지 줄, 작업 일지는 고른 일지(다시 누르면 지움) |
| `r` | 오늘 — 다음 항목을 터미널에서 실행 |
| `/` · `⌘F` | 작업 일지 — 일지 검색 |

## 터미널

| 키 | 동작 |
|---|---|
| `⌘T` | 새 세션 |
| `⌘D` / `⇧⌘D` | 고른 칸을 오른쪽 / 아래로 나누기 — 몇 번이든 |
| `⌥⌘` + 방향키 | 칸 사이 이동 |
| `⇧⌘↩` | 고른 칸만 크게 · 되돌리기 |
| `⌘F` | 출력에서 찾기 |
| `⌘L` | 고른 출력을 Claude 에게 보내기 |
| `⇧↩` | Claude · Codex 입력에서 줄바꿈 — 셸 · vim 에서는 그냥 `Enter` 입니다 |
| `⇧⌘[` / `⇧⌘]` | 이전 · 다음 세션 |
| `⌘=` / `⌘-` / `⌘0` | 글자 크게 · 작게 · 기본 |
| `⌘W` | 세션 닫기 (둘 이상일 때) |

Windows · Linux 에서는 셸이 `Ctrl+글자` 를 쓰므로 터미널 키에 `Shift` 를 하나 더 얹습니다 — `⌘T` 는 `Ctrl+Shift+T`, `⌘D` 는 `Ctrl+Shift+D`, `⇧⌘D` 는 `Ctrl+Alt+Shift+D`. 칸 이동은 `Ctrl+Alt+방향키`, 세션 오가기는 `Ctrl+PageUp` / `PageDown`, 글자 크기는 `Ctrl+=` · `Ctrl+-` · `Ctrl+0`, 복사 · 붙여넣기는 `Ctrl+Shift+C` / `V` 입니다.

:::note
앱 안 터미널은 2026-10-28 에 걷었다가 10-29 에 작게 돌아왔습니다 — 세션은 앱 안에 살고 창을 닫으면 끝납니다. 오늘의 `r` 과 계획 화면의 [터미널에서 실행] · [끝까지 (/goal)] 이 새 세션에서 `claude` 를 엽니다. 편집기 · 에이전트 채팅 화면은 돌아오지 않았습니다.
:::
