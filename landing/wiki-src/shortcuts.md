`⌘` 번호는 사이드바 순서에서 자동으로 나옵니다 — 각 화면이 무엇을 하는지는 [화면 둘러보기](/wiki/screens)에.

## 어디서나

| 키 | 동작 |
|---|---|
| `⌘K` | 커맨드 팔레트 — 화면 이동 + 일지·계획·토의·문서 제목 검색 |
| `⌘1` ~ `⌘8` | 화면 바로가기 — 사이드바 순서대로 (`⌘1` 오늘 현황 · `⌘2` 작업 일지 · `⌘3` 변경 · `⌘4` 플래너 · `⌘5` 검색 · `⌘6` 스킬·규칙 · `⌘7` 문제 해결 · `⌘8` 브랜치) |
| `⌘[` / `⌘]` | 화면 뒤로 / 앞으로 — 브라우저처럼, 방금 보던 화면으로 |
| `⌘P` | 프로젝트 전환 |
| `⌘,` | 설정 |

## 탭과 창

| 키 | 동작 |
|---|---|
| `⌘T` | 새 프로젝트 탭 |
| `⌘W` | 탭 닫기 |
| `⇧⌘N` | 새 창 |

:::note
앱 안 터미널 · 편집기 · Claude Code 화면과 그 전용 키는 2026-10-28 에 걷었습니다. 에이전트는 여러분의 터미널에서 돌고, 플래너 ▶실행과 오늘 화면의 「이어서 작업」은 프롬프트를 **클립보드**에 담아 줍니다.
:::
