`⌘` 번호는 사이드바 순서에서 자동으로 나옵니다 — 각 화면이 무엇을 하는지는 [화면 둘러보기](/wiki/screens)에.

## 어디서나

| 키 | 동작 |
|---|---|
| `⌘K` | 커맨드 팔레트 — 화면 이동 + 일지·계획·토의·문서 제목 검색 |
| `⌘1` ~ `⌘9`, `⌘0` | 화면 바로가기 — 사이드바 순서대로 (`⌘1` 오늘 현황 … `⌘9` 문서, `⌘0` 터미널) |
| `⌘P` | 프로젝트 전환 |
| `⌘J` | 터미널 도크 열기/닫기 — 어느 화면 위에서든 |
| `⌘\` | 에이전트(AI 패널) 화면 |
| `⌘,` | 설정 |

## 탭과 창

| 키 | 동작 |
|---|---|
| `⌘T` | 새 프로젝트 탭 |
| `⌘W` | 탭 닫기 (Claude Code 화면에서는 세션 탭부터) |
| `⇧⌘N` | 새 창 |

## Claude Code 화면

| 키 | 동작 |
|---|---|
| `⏎` | 전송 · `⇧⏎` 줄바꿈 |
| `Esc` | 실행 중인 턴 중단 |
| `⇧Tab` | 권한 모드 순환 (수동 → 편집 자동승인 → 계획 → 자동) |
| `↑` / `↓` | 보냈던 지시 되부르기 (빈 입력창에서) |
| `@` | 파일 멘션 자동완성 · `/` 슬래시 커맨드 |
| `←` / `→` | 세션 탭 사이 이동 (탭에 포커스가 있을 때) |

## 터미널

**포커스가 터미널 안에 있을 때만** 동작합니다 — 도크가 다른 화면 위에 얹혀 있어도, 일지를 읽던 중이라면 `⌘F` 가 스크롤백 검색을 열지 않습니다.

| 키 | 동작 |
|---|---|
| `⌘T` | 새 세션 (탭) |
| `⌘W` | 페인 닫기 |
| `⌘D` / `⇧⌘D` | 가로 분할 / 세로 분할 |
| `⌘F` | 스크롤백 검색 — `Enter` 다음 · `⇧Enter` 이전 · `Esc` 닫기 |
| `⌘L` | 화면 지우기 (`⌘K` 는 팔레트가 선점) |
| `⌘+` / `⌘−` | 글자 크기 · `⇧⌘0` 되돌리기 |
| 더블클릭 | 세션 탭 이름 바꾸기 |
| 자리 바꾸기 버튼 | 도크 위치 순환 — 아래 → 왼쪽 → 오른쪽 |
| 분리 버튼 | 터미널만 담은 별도 창으로 (셸 유지) |

:::note
`⌘T`·`⌘W` 는 전역(프로젝트 탭)과 터미널(세션·페인)에 둘 다 있습니다. 포커스가 어디 있느냐로 갈립니다.
:::
