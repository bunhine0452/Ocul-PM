사이드바의 **에이전트**(`⌘\`)는 여러 LLM 제공자와 대화하는 화면입니다. 앱 안 Claude Code 가 *코드를 고치는* 곳이라면, 여기는 *묻고 정리하는* 곳입니다.

:::note
이 화면은 여러분의 **API 키로 직접 호출**합니다. 키가 없으면 "무엇이든 물어보세요" 대신 키를 추가하라는 안내가 뜹니다 — [설정](/wiki/settings)에서 넣으세요. 기록 기능에는 키가 필요 없습니다.
:::

## 무엇이 다른가 — 컨텍스트가 붙는다

일반 챗봇과의 차이는 하나입니다. **이 프로젝트의 맥락을 질문에 붙여 보낼 수 있습니다.**

입력창 위의 칩으로 켜고 끕니다:

| 칩 | 붙는 것 |
|---|---|
| **코드** | 질문과 의미가 가까운 코드 조각 (로컬 검색으로 고름) |
| **작업일지** | 최근 일지 |
| **플래너** | 현재 계획의 항목과 상태 |
| **git** | 최근 커밋 흐름 |

그래서 이런 질문이 실제로 답이 됩니다:

- "이 프로젝트 구조를 한눈에 요약해줘"
- "최근 작업일지를 바탕으로 다음 할 일을 제안해줘"
- "플래너 진행 상황을 정리하고 리스크를 짚어줘"
- "최근 커밋 흐름을 리뷰해줘"

첫 화면에 이 네 개가 버튼으로 놓여 있습니다.

## 토큰 배지 — 얼마나 나갈지 미리 보기

입력창 옆에 **예상 입력 토큰**이 뜹니다. 눌러 보면 무엇이 얼마나 차지하는지 항목별로 나옵니다 — 시스템 프롬프트, 코드 N곳, 작업일지, 플래너, 액션 프로토콜.

:::warn
**매 전송마다 컨텍스트 + 대화 기록 전체가 다시 전송됩니다.** 대화가 길어질수록 한 번 보낼 때의 비용이 커집니다. 주제가 바뀌면 「새 대화」를 눌러 끊는 편이 쌉니다.
:::

배지는 휴리스틱 근사치(±30%)입니다. 정확한 청구액이 아니라 *감각*을 위한 숫자입니다.

## 플래너 액션 제안

이 화면의 특별한 점입니다. 대화 중 계획을 손볼 만한 지점이 나오면, 모델이 **제안 카드**를 냅니다:

| 제안 | 뜻 |
|---|---|
| 🗂 계획 생성 | 새 플래너 문서 |
| ➕ 항목 추가 | 기존 계획에 할 일 추가 |
| ✅ 상태 변경 | 항목 글리프 옮기기 |
| ✏️ 항목 이름변경 | |
| 🗑 항목 삭제 | |

**여러분이 승인해야 반영됩니다.** 누르면 플래너 파일에 실제로 적용되고 「✓ 반영 완료」로 바뀝니다. 모델이 멋대로 계획을 고치지 않습니다.

:::tip
"이번 주 한 일 보고 다음 스프린트 항목 만들어줘" 처럼 시키면, 작업일지 컨텍스트를 읽고 계획 항목을 제안까지 해 줍니다. 마음에 드는 것만 승인하면 됩니다.
:::

## 모델 고르기와 대화 기록

- **모델 선택** — 입력창 옆에서 그때그때 바꿉니다. 키가 있는 제공자만 뜹니다
- **새 대화 / 대화 기록** — 지난 대화를 다시 열 수 있습니다
- **생성 중지** — 답이 길어질 때 끊습니다
- `⏎` 전송 · `⇧⏎` 줄바꿈

## 작업 맥락 자동 주입

설정 → 인덱싱 & RAG 의 **「작업일지 · 규칙 자동 주입」** 을 켜면, 칩을 누르지 않아도 최근 일지와 AGENTS 규칙이 매 대화에 들어갑니다. 세션이나 모델을 바꿔도 작업 방향이 유지됩니다.

주입할 일지 수는 조절할 수 있습니다 — 많을수록 맥락이 풍부하지만 토큰을 더 씁니다. 0 으로 두면 규칙만 들어갑니다.

## 앱 안 Claude Code 와 어떻게 다른가

| | 에이전트 패널 | 앱 안 Claude Code |
|---|---|---|
| 하는 일 | 묻고 정리하기 | 코드를 실제로 고치기 |
| 비용 | 여러분의 API 키 | Claude 구독 자격 |
| 제공자 | 여럿 (Anthropic·OpenAI·Gemini·OpenRouter·NIM) | Claude |
| 파일 수정 | 안 함 (플래너 제안은 승인 후) | 함 |
