Ocul-PM 에서 Claude Code 는 **여러분의 터미널에서** 돕니다. 터미널의 `claude` 가 하는 일을 앱이 **기록 · 증거 · 계획**으로 받아 두고, 그중 사람이 볼 것만 펼치는 것이 이 앱의 자리입니다. 앱은 LLM 을 부르지 않습니다.

| 자리 | 무엇을 하나 | 설치 |
|---|---|---|
| **규칙 파일** `AGENTS.md` | 작업 하나를 끝낼 때마다 일지를 남기라고, 코드 전에 완료 조건을 결과로 말하고 판정은 확인 명령에 맡기라고 알려 줍니다 (템플릿 v20) | 기록을 켜면 자동 |
| **플러그인** `oculpm` | 훅(세션 시작 · 끝) · MCP 기록 도구 · 커맨드 — 기록이 규칙이 아니라 **구조**가 됩니다 | 아래 두 줄 |
| **앱** | 일지가 몇 초 안에 화면에 서고, diff 가 붙고, 판정 실패와 증거 없는 일지가 오늘 화면에 섭니다 | 받기만 |

## 플러그인을 설치하세요

AGENTS.md 규칙만으로도 일지를 남기지만, 그건 **모델이 규칙을 따라 주는 만큼**입니다 — 긴 세션 끝에 잊고 넘어갈 수 있습니다. 플러그인을 설치하면 세션이 끝날 때 훅이 판정하고, 코드를 고쳤는데 일지가 없으면 턴을 한 번 막아 기록하라고 말합니다.

터미널의 `claude` 안에서 두 줄입니다:

```
/plugin marketplace add bunhine0452/Ocul-PM
/plugin install oculpm@oculpm
```

:::tip
이 명령은 앱의 **설정 → 에이전트 연결**에도 복사 버튼과 함께 있습니다. 깔린 판이 앱보다 낮으면 같은 자리와 오늘 화면이 업데이트 명령을 줍니다.
:::

플러그인이 설치되면:

- **시작 훅** — 최근 갱신된 계획마다 완료 조건 · 확인 명령 · **마지막 판정** · 미완 항목, 그리고 마지막 일지 3건을 시작 컨텍스트에 싣습니다. 어제를 다시 설명하지 않습니다
- **끝 훅** — 일지 없이 끝났는지 판정합니다
- **MCP 도구 7종** — `journal_search` · `journal_read` · `journal_write` · `plan_status` · `plan_update` · `plan_create` · `project_init`
- **커맨드** — `/oculpm:inception`(그다음 → 깊이 네 질문 → 분야의 방법 → 어려운 숫자 목표 → 첫 항목이 지금 빨간 확인 명령인 계획) · `/oculpm:next`(잡은 항목을 `[~]` 로 먼저 선점 → 구현 → 확인 명령 → 일지 → 계획, `until-done` 이면 판정이 통과할 때까지) · `/oculpm:redteam`(주장을 직접 돌려 반례만) · `/oculpm:help`

전부 `~/.claude` 전역에 설정되므로 **모든 프로젝트에서** 동작합니다(`.oculpm/` 이 있는 프로젝트에서만 기록합니다). 앱 없이 플러그인만 먼저 써도 됩니다 — 기록은 `.oculpm/` 마크다운으로 쌓이고, 앱은 나중에 설치해도 그 기록을 그대로 읽습니다. 자세한 것은 [플러그인 페이지](/plugin)에.

## 판정 한 줄

확인 명령을 돌린 에이전트는 결과를 `plan_update` 의 메모로 `판정 ✓|✗ <결과 끝 줄>` 한 줄로 남깁니다. 시작 훅과 계획 화면이 같은 규칙으로 그 줄을 읽어 「마지막 판정」으로 보여 줍니다. 자세한 것은 [계획](/wiki/planner)에.

## 앱이 터미널에 넘기는 것

- **계획 화면 [프롬프트 복사]** · 오늘 화면 `c` — 다음 항목을 잡는 프롬프트를 **클립보드**에 담습니다. 터미널의 `claude` 에 붙여 넣고 Enter.
- **[until-done 으로 복사]** — 같은 프롬프트에 「판정이 통과할 때까지 이어 가라」를 붙입니다.
- **변경 화면 [기록 요청 복사]** — 어느 일지에도 없는 파일 목록으로 기록을 부탁하는 글을 만듭니다.

보내는 것은 언제나 여러분입니다 — 앱이 터미널에 직접 쓰는 길은 없습니다.

## 정리 — 무엇을 설치해야 하나요

- **Claude Code 를 터미널에서 쓴다** → 위 두 줄로 플러그인 설치. 이걸 안 하면 세션의 기록이 빠질 수 있습니다.
- **Codex · Cursor · Gemini CLI** → [다른 에이전트 연동](/wiki/agents).
