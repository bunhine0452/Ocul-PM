무엇이 나가고,
무엇이 절대 나가지 않는가.

「전부 로컬」은 주장이지 증거가 아닙니다. 그래서 목록으로 적습니다 — 앱이 여는 연결 전부와, 어떤 경우에도 열지 않는 것들. 계정이 없고, 우리 서버가 없고, 사용 통계와 크래시 리포트를 수집하지 않습니다.

나가는 것 · 안 나가는 것

왼쪽이 전부입니다. 앱은 LLM 을 부르지 않고, 화면(웹뷰)은 바깥 호스트에 닿지 않습니다 — 4.0 에서 앱 안 AI · GitHub 조회 · 번들 내려받기 · 임베딩 모델을 전부 걷었습니다.

나가는 것 — 두 갈래

이 두 갈래 말고는 없습니다. 둘 다 당신이 시작합니다.

  • 업데이트 확인 — 앱 시작과 수동 확인 시 github.com 의 릴리스 파일 한 장. 목적지는 앱 설정(tauri.conf.json)에 고정돼 있고, 받은 것은 서명을 검증합니다. 보내는 것은 요청 그 자체뿐입니다.
  • 당신이 누른 링크 — 저장소 · 이슈 · 릴리스 페이지 같은 링크는 앱이 보내지 않고 OS 의 기본 브라우저에 넘깁니다. http · https · mailto 가 아닌 주소는 거절합니다.

여기에 더해, 앱이 당신 대신 띄우는 도구는 그 도구 자신의 동작을 합니다 — 설정에 적은 외부 편집기 명령, 변경 화면이 읽는 로컬 git. 앱이 띄우는 하위 프로세스는 자리마다 「송출 가능 / 로컬」로 분류해 원장(egress_spawn_ledger.rs)에 묶어 두었습니다.

절대 안 나가는 것

기능이 아니라 구조입니다 — 보낼 코드가 없습니다.

  • 작업 일지 · 계획 — 앱은 그것을 어디에도 보내지 않습니다. 에이전트가 읽는 것은 당신의 터미널에서 도는 에이전트의 일입니다.
  • .oculpm/ 파일 전부 — 일지 · 계획 · 세션 · 캐시. 저장소 안에 있고, 당신의 git 이 아니면 아무 데도 가지 않습니다.
  • 소스 코드 — 앱 안에 LLM 클라이언트가 없습니다.
  • API 키 — 앱이 받지 않습니다. 3.x 가 키체인에 남긴 항목은 앱이 더 읽지도 지우지도 않습니다.
  • 사용 통계 — 수집하지 않습니다. 분석 SDK 가 앱에 들어 있지 않습니다.
  • 크래시 리포트 — 수집하지 않습니다. 오류는 기기의 oculpm.log 에만 남습니다.
  • 계정 — 만들 것이 없습니다. 로그인 화면이 없습니다.

믿지 말고 확인하세요

코어는 MIT 로 공개돼 있습니다. 위 목록은 저장소에서 직접 셀 수 있고, 빌드가 지킵니다 — src-tauri/tests/egress_inventory.rs 가 원장에 없는 새 송출을 빌드에서 막고, webview_csp.rs 가 화면의 connect-src 에 바깥 호스트가 돌아오면 실패합니다.

rg -n 'https://' src-tauri/src --type rust

기기 밖으로 나가는 것을 직접 보고 싶다면 Little Snitch · LuLu 같은 방화벽으로 앱을 감시해도 됩니다. 위 목록에 없는 호스트가 보이면 이슈로 알려 주세요 — 그건 버그입니다.

이 웹사이트

앱이 아니라 oculpm.com 이야기입니다. 이 사이트는 Vercel 에 정적으로 올라가 있고, 페이지 조회수를 세는 Vercel Analytics 스크립트가 하나 있습니다 (쿠키를 쓰지 않고 개인을 식별하지 않습니다). 상단 버전 배지는 GitHub 릴리스 API 를 한 번 부릅니다. 그 밖에 추적기·광고·폰트 CDN 이 없습니다.

English summary

Ocul is local-first: no account, no server of ours, no telemetry and no crash reporting — and since 4.0 the app calls no LLM and its screens (the webview) reach no outside host. Exactly two kinds of outbound connection exist, and you start both: (1) update checks against a GitHub release file, whose destination is fixed in the app configuration and whose signature is verified; (2) links you click, which the app hands to your OS default browser (only http, https and mailto). Tools the app launches for you do their own thing: the external-editor command you configured and the local git the Diff screen reads.

Never leaves the machine: your journal entries and plans, everything under .oculpm/, your source code (there is no LLM client in the app), usage statistics and crash reports (not collected at all). The app takes no API key. The core is MIT-licensed — the build keeps this list honest: src-tauri/tests/egress_inventory.rs fails on any outbound call that is not in its ledger, and webview_csp.rs fails if an outside host returns to the webview's connect-src.
