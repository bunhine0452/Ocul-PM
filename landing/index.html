1.0 다운로드 (macOS) 설치 방법

이렇게 동작해요

직접 기록하지 않아도 됩니다. 평소처럼 에이전트로 코딩하면, Ocul-PM 이 변경·작업 일지·통계를 자동으로 모아줍니다.

1

프로젝트 폴더 추가

폴더를 불러오면 Ocul-PM 이 코딩 에이전트용 규칙(AGENTS.md)을 자동으로 심어요.

2

평소처럼 에이전트로 코딩

Claude Code·Cursor·Gemini 등 쓰던 에이전트로 작업하면, 그 규칙에 따라 에이전트가 작업 일지를 남겨요.

3

자동으로 기록·정리

작업 일지·변경 diff·통계를 Today 화면에 모아 보여줍니다. 새 작업이 기록되면 실시간으로 갱신돼요.

핵심 기능

📓

자동 작업 일지

에이전트가 남긴 기록을 트리거(버그·기능·리팩토링·에러·잡일)별로 자동 분류. 플랫 markdown, DB lock-in 없음.

📊

Today 대시보드

오늘 무엇이 바뀌었는지·다음 할 일·주간 차트·에이전트 기여를 워크데이 경계로 한눈에.

🔍

변경 diff (로컬)

에이전트 변경을 네트워크 없이 즉시 비교. 일지별 diff 를 그 시점 그대로 영구 보관.

🧭

코드 검색

의미(임베딩)·심볼(AST)·정확(텍스트) 3 모드. 임베딩이 외부로 나가지 않습니다.

⌨️

내장 터미널

탭 기반 PTY 터미널. Today 에서도 바로 에이전트를 실행하고 일지가 쌓이는 걸 옆에서 봅니다.

✨

멀티-LLM AI 패널

Anthropic·OpenAI·Gemini 를 같은 인터페이스로. API 키는 OS 키체인에만 저장.

설치

GitHub Releases 에서 최신 .dmg 를 받으세요. (macOS · Apple Silicon)

macOS 설치

  1. Ocul-PM_1.0.0_aarch64.dmg 를 받아 열고, Ocul-PM 을 Applications 로 드래그합니다.
  2. 처음 열 때 "손상되었기 때문에 열 수 없습니다" 가 뜨면 — 아래 한 줄을 터미널에 붙여넣으세요.
xattr -dr com.apple.quarantine /Applications/Ocul-PM.app

⚠ "손상되었다"고 뜨는 이유

Ocul-PM 은 아직 Apple Developer 공증(notarization)을 받지 않은 오픈소스 빌드입니다. macOS 는 인터넷에서 받은 *공증 안 된* 앱에 격리(quarantine) 표시를 붙여 "손상됨"으로 차단합니다 — 실제로 손상된 게 아닙니다. 위 xattr 명령이 격리 표시만 제거합니다.

앱은 로컬에서만 동작하며, 코드는 GitHub 에 공개되어 있어 직접 빌드해 쓸 수도 있습니다.

소스에서 빌드

git clone https://github.com/bunhine0452/Ocul-PM cd Ocul-PM pnpm install pnpm tauri build # .dmg / .app

요구사항: Node 18+ · pnpm · Rust(stable) · (macOS) Xcode Command Line Tools
