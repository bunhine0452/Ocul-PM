화면 둘러보기

마지막 수정 2026-10-29

Ocul-PM 4.0 의 화면은 다섯 면과 터미널입니다. 원칙은 하나 — 예외만 보여 준다. 화면의 크기는 에이전트가 한 양이 아니라 사람이 볼 것에 비례하고, 하루 3건 쓰는 사람과 60건 쓰는 사람이 모드 없이 같은 화면을 씁니다. 에이전트는 앱 안 터미널 탭에서 돌려도 되고, 여러분의 터미널에서 돌려도 됩니다 — 기록은 똑같이 남습니다.

윗줄 탭 순서 = ⌘ 번호 순서입니다 (⌘1 ~ ⌘5). 설정은 윗줄 끝의 톱니(⌘,)입니다.

화면키하는 일
오늘⌘1「확인할 것」 — 판정 실패 · 명령 증거 없는 일지 · 어느 일지에도 없는 변경 · 막힘 · 사람 몫 결정 · 플러그인 새 판. 증거가 선 일은 계획별로 한 줄
작업 일지⌘2왼쪽 목록 + 오른쪽 상세(검증 상자 · 파일별 인라인 diff · 관련 일지). 일지 검색(/)이 여기 삽니다
계획⌘3제목 바로 아래 완료 조건 · 확인 명령 · 마지막 판정, 다음 항목을 터미널에서 실행. 끝난 단계는 한 줄로 접힘
변경⌘4커밋 전 / 최근 커밋의 diff. 「기록 없음」(어느 일지에도 없는 파일)이 먼저
터미널⌘5이 프로젝트 폴더의 셸. 왼쪽 세션 목록(도는 중 · 끝남 · 시작 뒤 일지 수) + 터미널. 오늘 · 계획의 「다음」 이 여기서 claude 를 엽니다. 세션은 창을 닫으면 끝납니다
설정⌘,에이전트 연결 · 이 프로젝트 · 표시 · 데이터, 한 쪽

프로젝트가 없는 창은 시작 창입니다 — 최근 프로젝트와, 처음이라면 세 단계(폴더 → 기록 켜기 → 플러그인 설치 명령 복사).

일지와 계획은 이 앱의 두 기둥입니다 — 각각 작업 일지와 계획에서 자세히 다룹니다.

팁

일지 상세와 변경 화면의 「열기」는 설정의 외부 편집기 명령(VS Code · Cursor …)으로 그 파일을 엽니다. 앱 안 편집기는 없습니다.

4.0 에서 걷은 화면

걷은 것대신
검색(의미 · 심볼 · 텍스트)일지 검색은 작업 일지(/), 코드 검색은 에이전트의 grep
문제 해결(논의)계획의 ## 결정 블록. .oculpm/discussion/ 파일은 지우지 않습니다
브랜치 · 스킬·규칙기록률은 오늘 · 변경의 「기록 없음」, 스킬은 플러그인
메뉴바 트레이 · 크롬식 탭창 하나 = 프로젝트 하나, OS 의 창 전환
간단 / 전문 밀도예외만 보여 주는 한 화면

근거(실측)는 저장소의 PROMISE.md 「4.0 에서 걷은 것」 표에 있습니다.
