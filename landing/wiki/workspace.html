창 · 탭 · 터미널 · 코드

마지막 수정 2026-08-21

이 페이지에서탭과 창메뉴바에 상주하기터미널코드 화면다음 걸음

화면이 무엇을 보여주는가는 화면 둘러보기에 있습니다. 이 문서는 그 화면들을 어떻게 늘어놓고 굴리는가입니다.

탭과 창

프로젝트마다 탭을 엽니다. 브라우저와 같은 감각입니다.

키동작
⌘T새 프로젝트 탭
⌘W탭 닫기
⇧⌘N새 창
⌘P프로젝트 전환 (사이드바 팝오버)
  • 탭마다 상태가 따로입니다 — A 프로젝트에서 일지를 보고 B 에서 터미널을 열어 둬도 서로 간섭하지 않습니다
  • 아직 안 열어 본 탭은 지연 로드됩니다 — 창을 열자마자 프로젝트 N 개가 한꺼번에 초기화되지 않습니다
  • 백그라운드 탭에서 에이전트가 돌면 활동 점이 붙습니다. 다른 프로젝트를 보는 중에도 눈에 띕니다
팁

창을 여러 개 띄우면 모니터에 프로젝트를 나란히 놓을 수 있습니다. 창끼리도 독립이라 한쪽에서 무거운 인덱싱이 돌아도 다른 창은 멀쩡합니다.

메뉴바에 상주하기

설정 → 모양 → 메뉴바에서 켭니다.

  • 메뉴바 아이콘 표시 — 상단바에 상태 아이콘이 뜨고, 에이전트 세션이 살아 있는 동안 움직입니다. 클릭하면 오늘 현황 팝오버
  • 창 닫기 = 메뉴바로 최소화 — 창을 닫아도 앱이 살아남아 세션 감지·기록을 계속합니다. 종료는 트레이 우클릭 → 종료
  • 상주 중 Dock 아이콘 숨김 — 최소화된 동안 Dock 에서도 사라집니다
  • 새 일지 알림 — 에이전트가 일지를 남기면 macOS 알림. 백필 등으로 몰릴 땐 10초에 3건까지만
참고

관측이 계속되려면 앱이 살아 있어야 합니다. 「메뉴바로 최소화」는 창을 치우면서도 관측은 유지하는 절충안입니다.

터미널

프로젝트 폴더에 붙은 진짜 셸입니다. 두 가지 모습으로 씁니다:

  • 전체 화면 — ⌘0
  • 도크 — ⌘J. 어느 화면 위에든 얹힙니다. 일지를 읽으면서 명령을 치기 좋습니다

도크는 아래 → 왼쪽 → 오른쪽으로 자리를 옮길 수 있고(자리 바꾸기 버튼), 분리 버튼을 누르면 터미널만 담은 별도 창이 됩니다 — 셸은 그대로 유지된 채로.

세션과 분할

터미널 안에 포커스가 있을 때 쓰는 키입니다:

키동작
⌘T새 세션 (탭)
⌘W페인 닫기
⌘D가로 분할 · ⇧⌘D 세로 분할
⌘F스크롤백 검색 (Enter 다음 · ⇧Enter 이전 · Esc 닫기)
⌘L화면 지우기
⌘+ / ⌘−글자 크기 · ⇧⌘0 되돌리기

세션 탭은 더블클릭으로 이름을 바꿉니다.

주의

⌘T·⌘W 는 전역(프로젝트 탭)과 터미널(세션·페인) 양쪽에 있습니다. 포커스가 터미널 안에 있을 때만 터미널 쪽이 먹습니다 — 도크가 다른 화면 위에 얹혀 있어도, 일지를 읽던 중이라면 ⌘F 는 터미널 검색을 열지 않습니다.

참고

⌘L 이 화면 지우기인 이유는 ⌘K 를 전역 커맨드 팔레트가 먼저 가져가기 때문입니다. 셸 자체의 Ctrl+L 은 그대로 통합니다.

터미널 글자 크기는 따로입니다

앱 전체 배율(설정 → 모양 → 글자 크기)과 별개로 px 단위로 정합니다. 터미널은 고정폭 격자라 배율보다 px 가 정확하기 때문입니다. 설정에서 정한 값은 터미널 화면·도크·분리 창에 모두 적용됩니다.

코드 화면

앱 안에서 파일을 보고 고치는 화면입니다. 왼쪽 트리에서 파일을 열고 오른쪽에서 편집한 뒤 저장합니다.

  • 점프해 들어오기 — 코드 검색·코드 맵 결과에서 「코드 화면에서 열기」로 바로 옵니다
  • 필터 — 트리 위 입력창으로 파일 이름 좁히기
  • 미저장 표시 — 고친 파일에 「수정됨」이 붙습니다
  • 외부 에디터로 열기 — 본격적인 편집은 평소 쓰는 에디터로 넘깁니다

한계도 분명합니다:

상황동작
2MB 초과열지 않습니다
바이너리미리볼 수 없다고 알립니다
파일이 너무 많음트리 일부만 표시
미저장 파일이 너무 많음가장 오래된 편집을 내려놓고 알려 줍니다
열어 둔 파일이 디스크에서 사라짐알려 줍니다

외부 에디터 연결

설정 → 모양 → 외부 에디터에서 명령 템플릿을 정합니다. %path 가 절대 경로로 치환됩니다.

code "%path"          VS Code
cursor "%path"        Cursor
subl "%path"          Sublime Text
주의

macOS GUI 앱은 셸의 PATH 를 물려받지 않습니다. code 만 적었는데 안 열린다면 절대 경로로 적으세요 — 예: /usr/local/bin/code "%path".
