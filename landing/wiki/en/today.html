On this pageOne columnTo checkNextDone todayKeysNext steps

⌘1 is the first screen you see. The principle is show only the exceptions — it unfolds only what a person must see and folds work with evidence into one line. 3 entries a day or 60, it's the same screen.

One column

Top to bottom: date · entries N → To check → Next (one line) → sessions working now (only when there are some) → Done today. Per-plan progress and passing verdicts live on the Plan tab — Today shows only failed verdicts and human-owned items, under To check.

To check

Sorted by severity. When it is empty, one calm paragraph remains — but if something couldn't be read, it doesn't claim there is nothing.

KindWhen it showsButtons
Failed verdictA plan's last verdict is ✗See output → that plan
No evidenceA bug · feature · refactor entry whose verification section has no command evidence, and no human has checked it (or it changed after the check)Checked (click the title to open the entry)
Unrecorded changeA file changed today that no entry mentions, or a conversation that ended without an entrySee changes
BlockedA plan item is [!]Open plan
Decision neededA human-owned ([user]) item is open — one row per planOpen plan
New plugin versionThe plugin installed for the project is older than the appCopy command

Next

The plan's next item (the first [ ] that isn't human-owned) on one line, with one "Run in terminal" button — claude picks it up in a new session on the Terminal tab. r does it too. To hand off to the end: /oculpm:next until-done.

Done today

Today's entries grouped by plan, with anything outside a plan under "Outside plans". Each group header shows count · evidence · none · checked — the target for the evidence share is a number in the promise document (97%). Up to 8 entries everything shows; past that, groups whose evidence is complete fold to their header line, and groups missing something show only those rows ("Show N more"). Switch between by-plan and by-time.

Keys

Only inside the screen — j/k move · Enter default action · v checked · r run the next item in the terminal.

Note

Before the first entry, one hint stands alone — it points to Settings → Agent connections. The 3.x stat cards · activity ring · commit graph · standup · weekly summary were removed in 4.0.
