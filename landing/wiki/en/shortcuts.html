Shortcuts

Last updated 2026-10-29

On this pageAnywhereWindowsToday · Work Journal

⌘ numbers come from the top-bar tab order automatically — what each screen does is in the Screens tour. On Windows · Linux, Ctrl replaces ⌘.

Anywhere

KeyAction
⌘KCommand palette — find screens · projects · entries · plans by title and open them
⌘1 – ⌘5Jump to a screen — ⌘1 Today · ⌘2 Work Journal · ⌘3 Plan · ⌘4 Diff · ⌘5 Terminal
⌘TTerminal — new session (Ctrl+Shift+T on Windows · Linux)
⌘\Terminal — another session side by side · back to one (Ctrl+Shift+\ on Windows · Linux)
⌘,Settings
⌘[ / ⌘]Back / forward between screens — like a browser
⌘/Shortcut cheatsheet
⌃Tab / ⌃⇧TabNext / previous screen (cycles)
Two-finger swipeBack / forward between screens (trackpad)

Windows

One window is one project — there are no tabs.

KeyAction
⌘ORecent projects — if it is already open, its window comes forward
⇧⌘NNew window (start window)
⌘WClose window — on macOS the app stays alive after the last one; a Dock click reopens
⌥⌘1 – ⌥⌘9Jump to an open project window — without opening a list (Alt+1 – Alt+9 on Windows · Linux)

Today · Work Journal

These keys listen only inside that screen.

KeyAction
j / kNext / previous item
EnterThe item's default action (see diff · open plan …)
vToday — mark read
rToday — run the next item in the terminal
/Work Journal — journal search
Note

The in-app terminal was removed on 2026-10-28 and came back, smaller, on 10-29 — sessions live inside the app and end when the window closes. r on Today and the Plan screen's [Run in terminal] · [To the end (/goal)] open claude in a new session. The editor and agent chat screens did not come back.
