Shortcuts

Last updated 2026-11-15

On this pageAnywhereWindowsToday · JournalTerminal

⌘ numbers come from the top-bar tab order automatically — what each screen does is in the Screens tour. On Windows · Linux, Ctrl replaces ⌘. Press ⌘/ in the app for the full table — the keys inside the Plan and Diff screens are there too.

Anywhere

KeyAction
⌘KCommand palette — finds terminal sessions (waiting first) · screens · actions (all shortcuts · open folder · open in your editor · project color …) · projects · plans · entries and opens them. Korean initial consonants work too (ㅇㅈ → Journal)
⌘JJump to the waiting session — the one that has waited longest first, again for the next. If none is in this window, it brings forward another project window that has one (Ctrl+Shift+J inside the terminal on Windows · Linux)
⌘1 – ⌘5Jump to a screen — ⌘1 Today · ⌘2 Journal · ⌘3 Plan · ⌘4 Diff · ⌘5 Terminal
⌘,Settings
⌘[ / ⌘]Back / forward between screens — like a browser
⌘/Shortcut cheatsheet
?Keys for this screen — only the current screen's keys in a small sheet (a plain character inside text fields and the terminal). Press again to close; "All shortcuts" opens the full table
⇧⌘CCopy receipt — on Today, an entry's detail, and Diff (Ctrl+Shift+C on Windows · Linux). On an entry's detail it copies that one entry
⌃Tab / ⌃⇧TabNext / previous screen (cycles)
Two-finger swipeBack / forward between screens (trackpad)

Windows

One window is one project — there are no tabs.

KeyAction
⌘ORecent projects — type to filter; if it is already open, its window comes forward
⇧⌘NNew window (start window)
⌘WClose window — in the terminal with several sessions, the selected session first. On macOS the app stays alive after the last window; a Dock click reopens
⌥TabRecent window — tap for the previous one, hold for the list in most-recent order (Ctrl+backtick on Windows · Linux)
⌥⌘1 – ⌥⌘9Project windows in most-recent order — without opening a list. The current window has no number (Alt+1 – Alt+9 on Windows · Linux)

Today · Journal

These keys listen only inside that screen.

KeyAction
j / kNext / previous item
EnterToday — the row's first button (Check again · Open plan · View changes …; a question opens its answer box) · Journal — open the detail
vMark read — on Today the unverified entry row, on Journal the selected entry (again to unmark)
rToday — run the next item in the terminal
/ · ⌘FJournal — journal search

Terminal

KeyAction
⌘TNew session
⌘D / ⇧⌘DSplit the selected pane right / down — as often as you like
⌥⌘ + arrowsMove between panes
⇧⌘↩Expand the selected pane · restore
⌘FFind in output
⌘LSend the selected output to Claude
⇧↩New line in Claude · Codex input — plain Enter in a shell or vim
⇧⌘[ / ⇧⌘]Previous · next session
⌘= / ⌘- / ⌘0Larger · smaller · default text
⌘WClose session (when there are several)

On Windows · Linux the shell owns Ctrl+letter, so terminal keys add one more Shift — ⌘T is Ctrl+Shift+T, ⌘D is Ctrl+Shift+D, ⇧⌘D is Ctrl+Alt+Shift+D. Moving between panes is Ctrl+Alt+arrows, switching sessions Ctrl+PageUp / PageDown, text size Ctrl+= · Ctrl+- · Ctrl+0, and copy · paste Ctrl+Shift+C / V.

Note

The in-app terminal was removed on 2026-10-28 and came back, smaller, on 10-29 — sessions live inside the app and end when the window closes. r on Today and the Plan screen's [Run in terminal] · [To the end (/goal)] open claude in a new session. The editor and agent chat screens did not come back.
