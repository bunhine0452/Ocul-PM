Ocul 위키

마지막 수정 2026-10-29

이 페이지에서처음이라면개념 — 무엇이 쌓이나에이전트 연동굴리는 법그 밖에

Ocul 을 쓰다 막히는 지점들을 모아 둔 설명서입니다. 짧게 쓰고, 자주 고칩니다. (4.0 기준)

4.0 의 앱은 다섯 면입니다 — 오늘 · 작업 일지 · 계획 · 변경 · 설정, 그리고 프로젝트가 없을 때의 시작 창. 원칙은 하나, 예외만 보여 준다: 사람이 볼 것(판정 실패 · 증거 없는 일지 · 기록 없는 변경 · 막힘 · 사람 몫 결정)만 펼치고, 증거가 선 일은 한 줄로 접습니다. 앱은 LLM 을 부르지 않습니다.

처음이라면

  • 시작하기 — 설치, 기록 켜기, 첫 일지가 쌓이기까지
  • 자주 묻는 질문 — 일지는 누가 쓰나, 돈이 드나, git 에 커밋해야 하나, 워크데이가 뭔가
  • 화면 둘러보기 — 다섯 면이 각각 무엇을 하는지 한 장으로

개념 — 무엇이 쌓이나

  • 오늘 — 앱을 열면 처음 보는 화면. 「먼저 볼 것」과 하루 한 줄
  • 작업 일지 — 일지가 언제 어떻게 쌓이는지, 검증 상자, 일지 검색
  • 계획 — 에이전트가 갱신하는 계획 문서. 완료 조건 · 확인 명령 · 마지막 판정

에이전트 연동

  • Claude Code 연동 — 플러그인(훅 · MCP 도구 · 커맨드) 설치, 규칙 파일이 하는 일
  • 다른 에이전트 연동 — Codex · Cursor · Gemini CLI · Copilot · Windsurf · Cline · Zed · aider · Antigravity

굴리는 법

  • 창 · 프로젝트 · 외부 편집기 — 창 하나 = 프로젝트 하나, 파일을 여는 외부 편집기
  • 설정 — 에이전트 연결 · 이 프로젝트 · 표시 · 데이터

그 밖에

  • 문제 해결 — 자주 겪는 불편과 해법 모음
  • 데이터와 파일 구조 — .oculpm/ 폴더, 백업과 이동, 로컬-우선의 실제 의미
  • 단축키 — 화면 이동, 창, 오늘 화면의 키
