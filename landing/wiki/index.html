Ocul-PM 위키

마지막 수정 2026-08-21

이 페이지에서처음이라면개념 — 무엇이 쌓이나에이전트 연동굴리는 법그 밖에

Ocul-PM 을 쓰다 막히는 지점들을 모아 둔 설명서입니다. 짧게 쓰고, 자주 고칩니다. (v2.14 기준)

처음이라면

  • 시작하기 — 설치, 프로젝트 추가, 첫 일지가 쌓이기까지
  • 자주 묻는 질문 — 일지는 누가 쓰나, 돈이 드나, git 에 커밋해야 하나, 워크데이가 뭔가
  • 화면 둘러보기 — 사이드바의 화면들이 각각 무엇을 하는지 한 장으로

개념 — 무엇이 쌓이나

  • 오늘 현황 — 앱을 열면 처음 보는 화면. 활동 링, 커밋 그래프, 스탠드업 복사
  • 작업 일지 — 일지가 언제 어떻게 쌓이는지, 변경 diff, 세션, 정직성 감사
  • 플래너 — 에이전트가 스스로 갱신하는 계획 문서. 글리프와 변경 로그
  • 회고 — 구간 신호 모으기, 미룬 지름길 원장, 스탠드업·PR 본문 생성

에이전트 연동

  • Claude Code 연동 — 앱 안에서 쓰기 vs 터미널에서 쓰기, 플러그인 설치, /plugin·/mcp 가 앱 안에서 안 되는 이유
  • 다른 에이전트 연동 — Cursor·Gemini CLI·Copilot·Windsurf·Cline·Zed·aider·Antigravity, 그리고 스킬·규칙 허브
  • 에이전트 패널 — 여러 LLM 에 같은 컨텍스트로 묻기, 토큰 배지, 플래너 액션 제안

굴리는 법

  • 창 · 탭 · 터미널 · 코드 — 여러 프로젝트를 동시에, 터미널 도크와 분할, 앱 안 코드 편집
  • 설정 — 테마와 프리셋, 글자 크기, API 키와 폴백, 인덱싱·RAG

그 밖에

  • 문제 해결 — 자주 겪는 불편과 해법 모음
  • 데이터와 파일 구조 — .oculpm/ 폴더, 백업과 이동, 로컬-우선의 실제 의미
  • 단축키 — 화면 이동부터 Claude Code 화면 전용 키까지
