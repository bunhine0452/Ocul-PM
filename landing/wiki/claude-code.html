Claude Code 연동

마지막 수정 2026-10-28

이 페이지에서플러그인을 설치하세요앱이 터미널에 넘기는 것정리 — 무엇을 설치해야 하나요

Ocul-PM 에서 Claude Code 는 여러분의 터미널에서 돕니다. 앱 안에서 Claude Code 를 구동하던 화면(ACP)은 2026-10-28 에 걷었습니다 — 터미널의 claude 가 하는 일을 앱이 기록 · 증거 · 계획으로 받아 두는 것이 이 앱의 자리입니다.

자리무엇을 하나설치
규칙 파일 AGENTS.md작업 하나를 끝낼 때마다 일지를 남기라고, 코드 전에 완료 조건·확인 명령을 말하라고 알려 줍니다프로젝트를 추가하면 자동
플러그인 oculpm훅 브리지(세션 시작·끝) · MCP 기록 도구 · 스킬 — 기록이 규칙이 아니라 구조가 됩니다아래 두 줄
앱일지가 몇 초 안에 화면에 서고, diff 가 붙고, 다음 세션이 어제를 이어받습니다받기만

플러그인을 설치하세요

AGENTS.md 규칙만으로도 일지를 남기지만, 그건 모델이 규칙을 따라 주는 만큼입니다 — 긴 세션 끝에 잊고 넘어갈 수 있습니다. 플러그인을 설치하면 세션이 끝날 때 훅이 판정하고, 코드를 고쳤는데 일지가 없으면 턴을 한 번 막아 기록하라고 말합니다.

터미널의 claude 안에서 두 줄입니다:

/plugin marketplace add bunhine0452/Ocul-PM
/plugin install oculpm@oculpm
팁

이 명령은 앱의 설정 → ocul-pm → 연동 탭에도 복사 버튼과 함께 있습니다. Claude Desktop 용 MCP 설정 스니펫도 같은 곳에서 복사합니다.

플러그인이 설치되면:

  • 훅 브리지 — 세션 시작 때 활성 계획의 미완 항목 · 완료 조건 · 확인 명령과 마지막 일지 3건을 시작 컨텍스트에 싣고, 끝날 때 일지 없이 끝났는지 판정합니다
  • MCP 도구 7종 — journal_search · journal_read · journal_write · plan_status · plan_update · plan_create · project_init
  • 스킬 — /oculpm:next(다음 미완 항목 한 바퀴) · /oculpm:redteam(주장을 직접 돌려 반례만) · /oculpm:inception(새 설계 시드) 등

전부 ~/.claude 전역에 설정되므로 모든 프로젝트에서 동작합니다. 앱 없이 플러그인만 먼저 써도 됩니다 — 기록은 .oculpm/ 마크다운으로 쌓이고, 앱은 나중에 설치해도 그 기록을 그대로 읽습니다. 자세한 것은 플러그인 페이지에.

앱이 터미널에 넘기는 것

  • 플래너 ▶실행 — 항목의 프롬프트(완료 조건 · 확인 명령 포함)를 클립보드에 담습니다. 터미널의 claude 에 붙여 넣고 Enter.
  • 오늘 화면 「이 맥락으로 이어서 작업」 — 남은 계획과 마지막 일지로 만든 이어하기 프롬프트를 클립보드에 담습니다.

보내는 것은 언제나 여러분입니다 — 앱이 터미널에 직접 쓰는 길은 없습니다.

정리 — 무엇을 설치해야 하나요

  • Claude Code 를 터미널에서 쓴다 → 위 두 줄로 플러그인 설치. 이걸 안 하면 세션의 기록이 빠질 수 있습니다.
  • Claude Desktop 도 쓴다 → 설정 → ocul-pm → 연동에서 MCP 스니펫 복사.
  • Codex · Cursor · Gemini CLI → 다른 에이전트 연동.
