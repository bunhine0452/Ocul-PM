Claude Code 연동

마지막 수정 2026-10-29

이 페이지에서플러그인을 설치하세요판정 한 줄앱이 터미널에 넘기는 것정리 — 무엇을 설치해야 하나요

Ocul 에서 Claude Code 는 여러분의 터미널에서 돕니다. 터미널의 claude 가 하는 일을 앱이 기록 · 증거 · 계획으로 받아 두고, 그중 사람이 볼 것만 펼치는 것이 이 앱의 자리입니다. 앱은 LLM 을 부르지 않습니다.

자리무엇을 하나설치
규칙 파일 AGENTS.md작업 하나를 끝낼 때마다 일지를 남기라고, 코드 전에 완료 조건을 결과로 말하고 판정은 확인 명령에 맡기라고 알려 줍니다 (템플릿 v20)기록을 켜면 자동
플러그인 oculpm훅(세션 시작 · 끝) · MCP 기록 도구 · 커맨드 — 기록이 규칙이 아니라 구조가 됩니다아래 두 줄
앱일지가 몇 초 안에 화면에 서고, diff 가 붙고, 판정 실패와 증거 없는 일지가 오늘 화면에 섭니다받기만

플러그인을 설치하세요

AGENTS.md 규칙만으로도 일지를 남기지만, 그건 모델이 규칙을 따라 주는 만큼입니다 — 긴 세션 끝에 잊고 넘어갈 수 있습니다. 플러그인을 설치하면 세션이 끝날 때 훅이 판정하고, 코드를 고쳤는데 일지가 없으면 턴을 한 번 막아 기록하라고 말합니다.

터미널의 claude 안에서 두 줄입니다:

/plugin marketplace add bunhine0452/Ocul-PM
/plugin install oculpm@oculpm
팁

이 명령은 앱의 설정 → 에이전트 연결에도 복사 버튼과 함께 있습니다. 깔린 판이 앱보다 낮으면 같은 자리와 오늘 화면이 업데이트 명령을 줍니다.

플러그인이 설치되면:

  • 시작 훅 — 최근 갱신된 계획마다 완료 조건 · 확인 명령 · 마지막 판정 · 미완 항목, 그리고 마지막 일지 3건을 시작 컨텍스트에 싣습니다. 어제를 다시 설명하지 않습니다
  • 끝 훅 — 일지 없이 끝났는지 판정합니다
  • 알림 훅 — Claude 가 사람을 기다리면(Notification) 앱 오늘 화면 맨 위에 「Claude 가 기다려요」 가 서고, 창이 뒤에 있으면 OS 알림이 옵니다
  • MCP 도구 8종 — journal_search · journal_read · journal_write · plan_status · plan_update · plan_create · project_init · ask_user(사람의 결정을 앱 오늘 화면에 묻고 답을 기다림, 25분 안)
  • 커맨드 — /oculpm:inception(그다음 → 깊이 네 질문 → 분야의 방법 → 어려운 숫자 목표 → 첫 항목이 지금 빨간 확인 명령인 계획) · /oculpm:next(잡은 항목을 [~] 로 먼저 선점 → 구현 → 확인 명령 → 일지 → 계획, until-done 이면 판정이 통과할 때까지) · /oculpm:redteam(주장을 직접 돌려 반례만) · /oculpm:help

전부 ~/.claude 전역에 설정되므로 모든 프로젝트에서 동작합니다(.oculpm/ 이 있는 프로젝트에서만 기록합니다). 앱 없이 플러그인만 먼저 써도 됩니다 — 기록은 .oculpm/ 마크다운으로 쌓이고, 앱은 나중에 설치해도 그 기록을 그대로 읽습니다. 자세한 것은 플러그인 페이지에.

판정 한 줄

확인 명령을 돌린 에이전트는 결과를 plan_update 의 메모로 판정 ✓|✗ <결과 끝 줄> 한 줄로 남깁니다. 시작 훅과 계획 화면이 같은 규칙으로 그 줄을 읽어 「마지막 판정」으로 보여 줍니다. 자세한 것은 계획에.

앱이 터미널에 넘기는 것

  • [터미널에서 실행](계획 화면 · 오늘 화면 r) — 앱 안 터미널에 새 세션을 열고 다음 항목을 잡는 프롬프트로 claude 를 띄웁니다. claude 명령을 찾지 못하면 그렇다고 알려 줍니다.
  • [끝까지 (/goal)] — claude 를 띄우고 입력을 기다리면 계획의 완료 조건 · 확인 명령을 Claude Code 의 /goal 로 넘깁니다. 조건이 참이 될 때까지 이어 갑니다.
  • 「Claude 에게 보내기」(일지 · 계획 항목 · 변경 파일) — 그 맥락을 붙인 글을, 입력을 기다리는 앱 안 claude 세션에 붙여 넣습니다. 그런 세션이 없으면 새로 엽니다.
  • 변경 화면 [Claude 에게 맡기기] — 어느 일지에도 없는 파일 목록으로 기록을 부탁합니다.

앱이 터미널에 쓰는 것은 여러분이 이 버튼을 누를 때뿐이고, 앱 밖 터미널에는 쓰지 않습니다. 반대 방향 — Claude 가 사람에게 묻는 것 — 은 ask_user 도구가 맡습니다: 질문이 오늘 화면에 서고, 고르거나 쓴 답이 그대로 Claude 에게 돌아갑니다.

정리 — 무엇을 설치해야 하나요

  • Claude Code 를 터미널에서 쓴다 → 위 두 줄로 플러그인 설치. 이걸 안 하면 세션의 기록이 빠질 수 있습니다.
  • Codex · Cursor · Gemini CLI → 다른 에이전트 연동.
