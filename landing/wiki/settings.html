앱 안 AI 는 없습니다

4.0 의 앱은 LLM 을 부르지 않습니다 — API 키 · 모델 · 폴백 설정이 없습니다. 요약이나 보고서는 터미널의 에이전트에게 시키고, 에이전트는 MCP 도구(journal_search · journal_read)로 쌓인 일지를 읽습니다. 3.x 가 키체인에 남긴 API 키 항목은 앱이 더 읽지도 지우지도 않습니다.

업데이트

평소에는 앱이 알아서 확인합니다. 데이터 칸의 「업데이트 확인」으로 수동 확인하고, 새 판이 있으면 「설치하고 다시 시작」을 누릅니다. Linux deb 로 설치했다면 앱 안 업데이트 대신 릴리스 페이지에서 새 .deb 를 받습니다. 최신 릴리스에 이 OS 용 빌드가 없으면 「이 OS 의 새 판이 아직 없어요」 라고 말합니다 — 오류가 아닙니다.
