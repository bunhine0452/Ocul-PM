모양

테마

밝게 / 어둡게 / OS 설정 위에 프리셋 테마를 얹는 2층 구조입니다.

  • 프리셋 5종 — Solarized · Sepia · Nord · Dracula · High Contrast
  • 액센트 컬러 6종 — 그린(기본) · 블루 · 퍼플 · 오렌지 · 로즈 · 틸
참고

프리셋을 고르면 액센트 선택이 비활성화됩니다. 프리셋은 자체 색 체계를 통째로 들고 오기 때문입니다. 액센트만 바꾸고 싶다면 프리셋 없이 밝게/어둡게/OS 테마를 쓰세요.

글자 크기 둘

앱 배율과 터미널 글자 크기는 별개입니다.

단위적용 범위
글자 크기배율 (%)앱 전체 — 브라우저 확대/축소처럼
터미널 글자 크기px터미널 화면·도크·분리 창

터미널이 px 인 이유는 고정폭 격자라 배율보다 px 가 정확해서입니다. 터미널 안에서는 ⌘+ / ⌘− 로 바로 조절하고 ⇧⌘0 으로 되돌립니다.

언어 둘

UI 언어(화면 텍스트)와 AI 작성 언어(AI 가 만드는 일지·플래너·회고의 언어)가 따로입니다. 영어 화면으로 쓰면서 기록은 한국어로 남길 수 있습니다. 이미 기록된 문서는 바뀌지 않습니다.

메뉴바 · 외부 에디터

메뉴바 상주와 외부 에디터 연결은 창·탭·터미널·코드에서 다룹니다.

LLM

AI 기능(회고 서술 생성, AI 패널 대화)을 쓸 때만 필요합니다. 기록 자체에는 키가 필요 없습니다.

API 키

OS 키체인에만 저장됩니다 — 앱 DB 나 파일에는 들어가지 않습니다. 상태(저장됨/미설정)는 로컬에 캐시되므로 설정을 열 때마다 키체인 프롬프트가 뜨지 않고, 정말로 대조하고 싶을 때만 「키체인 대조 확인」을 누릅니다.

프로바이더와 모델

기본 프로바이더를 고르고, 원하면 프로바이더별 모델을 덮어씁니다. 비우면 내장 기본값을 씁니다.

  • OpenRouter — 수백 개 모델을 OpenAI 호환으로. 모델 id 예: openai/gpt-4o
  • NIM — integrate.api.nvidia.com 의 OpenAI 호환 엔드포인트

폴백 체인

기본 모델 호출이 실패하면 위에서부터 차례로 재시도합니다. 한 줄에 하나씩 provider:model 형식입니다.

openai:gpt-4o-mini
anthropic:claude-3.5-haiku-latest
openrouter:openai/gpt-4o
팁

레이트리밋이 잦은 시간대에 회고를 돌린다면 폴백 체인이 실질적인 차이를 만듭니다.

생성

Temperature(낮을수록 집중, 높을수록 창의적), 최대 출력 토큰, 그리고 모든 채팅 앞에 붙는 시스템 프롬프트를 정합니다.

인덱싱 & RAG

코드 검색이 기대와 다를 때 여는 탭입니다.

  • 변경 시 자동 인덱싱 — 파일이 바뀌면 바뀐 파일만 곧바로 인덱싱합니다. 처음부터 다시 만들려면 인덱스 재구축
  • 청킹 — 청크가 클수록 스니펫당 맥락이 풍부하고, 작을수록 검색 정밀도가 높습니다. 오버랩은 청크 크기보다 작아야 합니다
  • RAG 컨텍스트 — 채팅 메시지마다 모델에 넘길 상위 청크 수
  • AI 작업 맥락 — 최근 작업 일지와 AGENTS 규칙을 채팅에 자동 주입해, 세션·모델이 바뀌어도 작업 방향이 유지됩니다. 주입할 일지 수가 많을수록 맥락은 풍부하지만 토큰을 더 씁니다 (0 이면 규칙만)
  • 파일 스캔 — 최대 파일 크기, 추가 제외 패턴(gitignore 스타일, .gitignore 위에 적용)
주의

스캔 설정 변경은 다음 재인덱싱 때 적용됩니다. 바로 반영하려면 인덱스를 재구축하세요.

그래프

코드 맵의 기본값입니다 — 고립된 파일을 기본으로 보일지, 그리고 자동 그룹 임계값(이 개수 이상의 파일을 가진 디렉터리는 접을 수 있는 그룹이 됩니다).

큰 저장소에서 맵이 빽빽하면 임계값을 낮추고, 너무 뭉뚱그려지면 올립니다.

Notion 내보내기

회고·산출물을 지정한 부모 페이지 아래 새 페이지로 내보냅니다. 브라우저에서 계정으로 연결하거나 internal token 을 직접 넣습니다. 토큰도 OS 키체인에만 저장됩니다.

진단 · 업데이트

  • 진단 — 문제를 신고할 때 붙일 정보. DevTools 도 여기서 엽니다
  • 업데이트 — 수동 확인과 과거 패치노트(GitHub releases). 평소에는 앱이 알아서 업데이트합니다
참고

업데이트 재시작은 앱과 함께 Claude Code 어댑터도 새로 띄웁니다. 그래서 답변이 흐르는 동안에는 재시작을 미룹니다 — 대화는 디스크에 있어 돌아오지만 그 순간의 답변 하나는 잃기 때문입니다.

ocul-pm

에이전트 규칙을 관리하는 탭입니다 — 어떤 에이전트의 규칙 파일을 깔지 고르고, 규격이 올라갔을 때 「규칙 다시 보내기」 로 갱신하고, 「감지」 로 이 프로젝트에서 쓰이는 것 같은 에이전트를 추립니다. 플러그인 설치 명령과 Claude Desktop 용 MCP 스니펫도 복사 버튼과 함께 여기 있습니다. (자세히)
