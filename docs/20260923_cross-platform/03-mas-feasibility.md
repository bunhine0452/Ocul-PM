# Mac App Store — 기능별 샌드박스 호환과 결정 게이트

2026-09-23 · 플랜 `mac-app-store` 의 M0 산출물.

> **결정 (2026-09-23, 사용자): Mac App Store 에는 출시하지 않는다.** 플랜의 나머지 항목은
> 전부 폐기했다. 이 문서는 그 판단의 근거로 남긴다 — 논의가 다시 열리면 아래 표에서 출발한다.

## 전제

Mac App Store 앱은 **App Sandbox 가 필수**다. App Review Guidelines 2.4.5 의 Mac 조항이
요구하는 것 중 이 앱과 부딪히는 것: 샌드박스, 지정된 컨테이너 밖 읽기·쓰기 제한,
기능을 더하는 코드의 다운로드·설치 금지, 사용자 동의 없이 앱 종료 뒤에도 도는 프로세스 금지,
스토어 밖 업데이트 금지. (제출 전 최신 가이드라인 원문과 대조할 것 — 조항 번호와 문구는 바뀐다.)

샌드박스의 결정적 성질: **샌드박스 앱이 띄운 자식 프로세스는 샌드박스를 물려받는다.**
내장 터미널에서 띄운 `claude`·`codex`·`git` 도 앱 컨테이너 밖을 못 본다.

## 기능별 판정

| 기능 | 샌드박스 판정 | Lite 에서의 처리 |
|---|---|---|
| 일지·플래너·검색·Today·Diff 보기 (`.oculpm` 읽기/쓰기) | 가능 — 사용자가 고른 폴더 + security-scoped bookmark | 유지 (북마크 저장·복원 필요) |
| 파일 감시 (notify/FSEvents) | 북마크로 접근이 유지되는 동안 가능 | 유지 |
| 내장 터미널 (PTY 호스트 · 셸) | 불가 — 셸이 샌드박스를 물려받아 사용자 도구·홈을 못 봄. 앱 종료 뒤 생존하는 PTY 호스트는 조항 위반 | 제외 |
| ACP 패널 (Claude Code · Codex) | 불가 — 외부 `node`/`npx` 실행, 에이전트가 홈 설정 필요 | 제외 |
| LSP · DAP | 사용자 설치 바이너리 실행 → 샌드박스 상속으로 대부분 실패 | 제외 |
| 훅·MCP 등록 (`~/.claude/settings.json` · Claude Desktop 설정 · `~/.codex/config.toml`) · 셸 통합(`.zshrc`) · 심 | 홈 파일 쓰기 = temporary-exception 엔타이틀먼트 → 심사 거절 위험 높음 | 제외, "복사해서 붙여 넣기" 안내로 대체 |
| MCP 사이드카 `oculpm-mcp` | 번들 안 헬퍼는 샌드박스로 서명돼야 하고, 다른 앱이 실행해도 **샌드박스 상태로** 돈다 → 프로젝트 폴더 접근 불가 | 제외 — **기록 루프가 끊긴다.** 기록은 앱 밖 플러그인이 자체 바이너리로(별도 배포), MAS 앱은 보기 전용 |
| git (`/usr/bin/git` 셸 아웃) | 불확실 — `/usr/bin/git` 은 xcode-select 셤. 샌드박스 안에서 CLT 호출이 되는지 실측 필요 | 실측 후 결정. 안 되면 gitoxide 내장 또는 Diff 제외 |
| 임베딩 모델 다운로드 (fastembed) | 데이터 다운로드라 허용 범위로 보임 + `network.client` | 유지 (컨테이너 경로) |
| LLM API 호출 · Notion | `network.client` | 유지 |
| 키체인 | 앱 자신의 항목은 가능 | 유지 |
| 자체 업데이터 (tauri-plugin-updater) | 금지 | 제외 (스토어 업데이트) |
| 플러그인·스킬 번들 설치 (GitHub) | "기능을 더하는 코드 다운로드" 로 볼 위험 | 제외. 테마(데이터)는 유지 가능 |
| 트레이 투명 팝오버 (`macOSPrivateApi`) | 비공개 API 사용 → 거절 사유 | 불투명 팝오버로 대체 |
| `MallocLargeCache` self re-exec | 기술적으로 가능하나 필요 없음 | 제외 |
| 모바일 브리지 (로컬 HTTP 서버) | `network.server` 엔타이틀먼트 — 심사 설명 필요 | 보류 |
| 딥링크 `oculpm://` · 단일 인스턴스 | 가능 | 유지 |

## 결론 초안

MAS 판은 **"일지·플래너 뷰어 + AI 요약"** 이 된다. 이 제품의 핵심 가치인 "에이전트가 한 일을
자동으로 기록한다" 는 루프(터미널·ACP·훅·MCP)가 전부 빠진다. 기록은 앱 밖 플러그인이 하고
MAS 앱은 보기만 하는 구조라면 성립은 하지만, 사용자는 "앱스토어에서 받았는데 기록이 안 된다"
를 겪는다.

비용: 별도 SKU(cargo feature + 프런트 플래그), 북마크 저장·복원, git 대체 가능성, 별도 번들 id,
심사 반려 대응, 두 판의 기능 차이 설명.

**권고: 보류.** 개발자 도구의 발견성이 목적이라면 **Homebrew cask**(`brew install --cask`)가
훨씬 싸고 이 앱의 모든 기능을 그대로 준다. MAS 는 Windows·Linux 베타가 졸업한 뒤 다시 판단한다.
