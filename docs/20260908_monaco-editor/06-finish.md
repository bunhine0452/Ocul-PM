# Phase 6 — 마감: 게이트 · 육안 격자 · 성능

> 플랜: [`monaco-editor-round`](../../.oculpm/planner/monaco-editor-round.md) `{#finish}`
> 앞선 단계: [`05-agent-surface.md`](05-agent-surface.md).

이 라운드는 **보이는 것을 통째로 바꿨는데** 자동 게이트만으로 판정했다. 남은
셋 중 둘(육안 · 기기 성능)은 사람이 앱을 띄워야 답이 나온다. 여기 적는 것은
그 절차와, 지금 답이 나온 것들이다.

## 자동 게이트 — 전부 초록 {#gates}

| 게이트 | 결과 |
|---|---|
| `pnpm typecheck` | exit 0 |
| `pnpm test` | 193파일 **2,514개** 통과 |
| `pnpm lint` (6종) | storage · i18n · bindings · design · file-size · eslint 전부 통과 |
| `pnpm build` | exit 0 (핵심 선택자 12개 확인 포함) |
| `cargo test` | exit 0 — **33 스위트 1,587개** 통과, 경고 0 (*아래 §cargo*) |

⚠️ **경고 한계와 래칫에 여유가 없다.** eslint 는 `--max-warnings=9` 이고 지금
정확히 9다. 파일 크기 래칫은 이 라운드에서 네 번 걸렸고(`CodePane` 세 번 ·
`CodeScreenV2` 한 번), 그때마다 같은 파일에서 낡은 주석을 줄이거나
(`useCodeAi` · `useCodeFormat`) 훅을 뽑아 갚았다. 다음 사람이 여기에 한 줄을
더하려면 한 줄을 빼야 한다 — 그게 래칫이 하라는 일이다.

### `cargo test` 를 파이프에 물리지 말 것 {#cargo}

처음엔 `cargo test 2>&1 | tail -40` 로 돌렸고 **exit 0 을 받았다.** 그건
`tail` 의 종료 코드다. 로그도 마지막 40줄뿐이라 "4 스위트 20개 통과" 라는
말도 안 되는 합계가 나왔다 — 실제로는 **33 스위트 1,587개**다. 그 숫자가
이상하지 않았으면 파이프 끝의 0 을 그대로 초록으로 적을 뻔했다.

같은 함정을 이 저장소는 이미 한 번 만났다(`gh run watch --exit-status` 를 파이프에
물려 취소된 run 을 초록으로 읽은 사고). **판정은 파이프 끝이 아니라 명령 자체의
종료 코드로 한다.**

```bash
cd src-tauri && cargo test > /tmp/cargo-test.log 2>&1; echo "exit=$?"
```

덤으로 확인한 것: `cargo test` 는 `bindings.ts` 를 다시 만드는데, 돌린 뒤
**해시가 한 바이트도 안 바뀌었다**. 이 라운드가 백엔드 커맨드를 하나도 안 늘렸다는
뜻이고(D6 이 프로바이더 채팅을 고른 부수 효과), 그래서 병렬 세션이 그 파일에
들고 있던 미커밋 변경도 안 건드렸다.

## 육안 확인 격자 {#eyes}

> 이 절은 **사람이 앱을 띄워 걷는 목록**이다. `{#fin-eyes}` 는 이것이 끝나기
> 전에는 닫히지 않는다. v3-release `{#eyes-hljs}` 가 요구하는 격자와 겹치므로
> 한 번에 갚는다.
>

### A. 색 — 라이트/다크 × 프리셋 5종

편집기의 색은 이제 **CSS 가 아니라 `defineTheme`** 이 준다. `data-theme` ·
`data-preset` 을 바꿀 때 `monaco/theme.ts` 의 감시자가 테마를 다시 정의하는데,
그 다리가 끊기면 **프리셋만 안 바뀐다** — 나머지 화면은 멀쩡하고 코드 색만
옛것으로 남는 모양이라 눈에 잘 안 띈다.

- [ ] 코드 화면에서 프리셋을 5종 모두 돌린다. 매번 **본문 색이 실제로 바뀌는가.**
- [ ] 라이트↔다크 전환도 같은 자리에서.
- [ ] 언어별로: `.ts` · `.rs` · `.py` · **`.json`** · **`.toml`** · `.sh` · `.md`.
      **json·toml 이 무채색이면 회귀다** — 그 둘은 우리가 직접 쓴 Monarch 다
      (`monaco/langExtra.ts`). `package.json` · `src-tauri/Cargo.toml` 이면 된다.
- [ ] 선택색 · 커서 · 활성 줄 강조가 프리셋을 따르는가.

### B. 새로 켠 것들

- [ ] **미니맵**이 오른쪽에 뜨는가. 설정에서 끄면 사라지는가(설정 → 코드).
- [ ] **폴딩** 화살표가 줄번호 옆에 뜨고 접히는가.
- [ ] **브래킷 쌍 색칠**과 **들여쓰기 가이드**가 보이는가.
- [ ] 괄호 위에 커서를 두면 짝이 표시되는가.
- [ ] `(` 를 치면 `)` 가 따라오고, 선택해 두고 `(` 를 치면 감싸는가.

### C. 스티키 스크롤 — 심볼로 바뀌었다

Phase 1 은 들여쓰기 모델이었고 Phase 2 가 **LSP 심볼 공급자**로 올렸다.

- [ ] 설정에서 스티키를 켠다. `.rs`/`.ts` 처럼 **언어 서버가 붙는** 긴 파일을
      스크롤 — 감싸는 `impl`/`fn`/`class` 가 맨 위에 붙는가.
- [ ] 언어 서버가 **없는** 파일(`.css` · `.md`)에서도 들여쓰기로 붙는가
      (사슬이 스스로 떨어지는지).
- [ ] 겹칠 줄 수 설정(1–10)이 먹는가.

### D. 키 — 조용히 뒤바뀌기 가장 쉬운 자리

| 키 | 떠야 하는 것 |
|---|---|
| ⇧⌘O | **우리 `CodeGoto`** (미리 점프 + `:줄` 겸용). Monaco 의 quickOutline 이 뜨면 회귀 |
| ⌘F / ⌥⌘F | Monaco 내장 찾기 / 바꾸기 (편집기 안) |
| ⇧⌘F | 프로젝트 전역 검색 패널 (트리 자리를 바꿔 앉는다) |
| ⌘K | ⌘K 인라인 편집 위젯 |
| ⌘D | 다음 일치에 커서 추가 |
| ⌥클릭 · ⌥⇧드래그 | 커서 추가 · 열(블록) 선택 |
| ⌘S | 저장 **한 번** (편집기 안에서도 두 번 안 나가는지) |
| **⌘V** | 편집기 안에서 **글자 붙여넣기**. 파일 트리 붙여넣기가 나오면 회귀 |
| ⌘X | 편집기 안에서 글자 잘라내기 |

마지막 둘은 Phase 2 가 고친 실제 회귀다(가드가 `.cm-editor` 를 보고 있었다).

### E. 위젯

- [ ] 호버 — 폭 480 안에서 접히는가, 시그니처(고정폭)와 문서(본문체)가 갈리는가.
- [ ] 진단 밑줄 — **물결선이 아니라** 실선(오류)·파선(경고)·점선(정보)인가.
- [ ] 시그니처 힌트 — 인자를 치는 동안 **지금 인자**가 강조되는가.
- [ ] git 거터(줄번호 왼쪽 3px 띠) · 중단점(glyph margin 원)이 제자리인가.
- [ ] 인라인 비교(일지/판 비교) — 추가 초록 · 삭제 빨강 · 되돌리기 화살표.

### F. ⌘K 인라인 편집

- [ ] 몇 줄을 선택하고 ⌘K — 위젯이 **선택 위**에 뜨고 입력창에 바로 포커스가 오는가.
- [ ] 지시를 넣고 Enter — 제안이 본문에 앉고 **받은 줄이 초록**인가.
- [ ] 조각이 둘 이상일 때 토글을 끄면 **그 조각만 원문으로** 돌아오는가.
- [ ] "되돌리기" 가 **원문 그대로**로 되돌리는가. 그 뒤 ⌘Z 한 번으로 더 이전으로.
- [ ] 상태줄에 "AI 가 고친 자리 N곳" 칩이 뜨고, 누르면 일지에 초안이 생기는가
      (일지 화면에서 그 항목의 `agent` 가 프로바이더·모델인지, 미검증 표시인지).
- [ ] 프로바이더 키가 없을 때 — 실패 문구가 위젯 안에 읽히게 뜨는가.

### G. 논의 편집기 (Phase 4)

- [ ] `##` 섹션 제목이 **강조색**, `###` 는 본문색인가 (단계가 갈리는가).
- [ ] `{#opt-a}` 같은 안정 id 가 따로 칠해지는가.
- [ ] 캐럿이 강조색 2px인가 · 빈 문서에서 자리표시자가 뜨는가.
- [ ] 본문이 가운데 78ch 로 묶이고 줄바꿈되는가 (가로 스크롤이 안 생기는가).
- [ ] ⌘B · ⌘I · ⌘K(링크) · ⌘S · ⌘F 가 먹는가.
- [ ] 삽입 메뉴("후보 방안" 등)가 **섹션 안 제자리**에 넣는가.

## 성능 {#perf}

### 지금 답이 나온 것 — 페이로드

| | 이관 전 | 지금 |
|---|---:|---:|
| `CodeScreenV2` 청크 | 335 KB | 145.08 KB (gzip 45.20) |
| `DiscussionEditor` 청크 | 537.97 KB (CodeMirror) | **8.75 KB** (gzip 3.34) |
| 공유 Monaco 청크 | — | 3,871.14 KB (gzip 1,001.45) |

| `dist/assets` 총합 | — | 16.3 MB |

읽는 법: **CodeMirror 538KB 가 앱에서 완전히 사라졌고**, 두 화면이 같은 Monaco
를 쓰게 되어 Rollup 이 공유 청크로 뽑았다. 코드 화면을 이미 연 뒤에는 논의
화면을 여는 비용이 0 이다(같은 청크).

Phase 0 의 D1 판정(언어 워커를 끈다)이 계속 유효한 근거도 여기 있다 — 워커를
켰다면 `.dmg` 에 **9.2MB** 가 더 실렸을 것이고, 지금 워커는 `editor.worker`
273KB 하나뿐이다.

### 아직 답이 없는 것 — 기기 지연 {#perf-todo}

플랜이 요구한 셋(**대용량 파일 열기 · 스크롤 · 타이핑 지연**)은 실기기에서
재야 한다. Phase 0 은 버리는 브랜치에 Rust 커맨드 하네스를 심어 쟀고
(`t0 → 편집 가능 221ms`, debug 빌드 · 콜드), 그 하네스는 지금 트리에 없다.

절차(다음에 앱을 띄울 때):

1. 큰 파일을 연다 — 이 저장소에서는 `src/lib/bindings.ts`(약 8천 줄) ·
   `src/features/code/code.css`(약 2.6천 줄)가 손에 있다.
2. 열기: 탭을 누른 순간부터 글자가 보일 때까지. 체감으로 **눈에 띄는 멈춤이
   있는가** (Phase 0 의 221ms 는 눈에 안 띄는 값이다).
3. 스크롤: 끝까지 훑어 프레임이 끊기는가. 미니맵을 끄면 달라지는가.
4. 타이핑: 파일 중간에서 한 문단을 친다. 특히 **한글 IME 조합 중** 멎는 곳이
   있는가 (Phase 0 이 IME 를 초록으로 판정한 것은 정확성이지 지연이 아니다).

숫자가 나오면 이 절을 `06-performance` 표로 바꾸고 Phase 0 의 221ms 와 나란히
둔다.

## 이 라운드가 닫지 못한 것 {#carried}

둘 다 **같은 이유**로 막혔다: 백엔드 커맨드를 더하면 `cargo test` 가
`src/lib/bindings.ts` 를 다시 만드는데, 그 파일은 병렬 세션(firing-ledger ·
rules · skills)이 미커밋 변경으로 들고 있다. 재생성하면 남의 진행 중 API 가
내 커밋에 섞이고, 안 하면 내 커맨드의 바인딩이 빠져 남의 체크아웃에서 타입이
깨진다.

| 항목 | 무엇이 남았나 | 해제 조건 |
|---|---|---|
| `{#cap-semantic}` | LSP `semanticTokens` 커맨드 + Monaco 공급자 | 병렬 세션 머지 |
| `{#agent-attribution}` | 로컬 히스토리의 `HistorySource` 가 ⌘K 편집을 `user` 로 적는다 — `code_write` 에 인자 하나 | 〃 |

`{#agent-tab-predict}`(Tab 다음-편집 예측)는 막힌 것이 아니라 **플랜대로 안 연
것**이다 — 전용 모델 · 지연시간 예산 · 취소 병합 · 오답 비용이 각각 설계를
요구한다.
