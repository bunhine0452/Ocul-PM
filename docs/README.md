# `docs/` 색인

이 폴더에는 마크다운 문서 **206개**가 있고, 그중 **약 2/3 는 이미 끝난 라운드의
기록**이다. 그런데 아카이브 문서 여럿이 스스로를 "단일 소스 오브 트루스" 라고
부른다 — 2026-05-20 의 `refactor/MASTER-GUIDE.md` 는 "향후 모든 PR·이슈·논의는 이
문서를 기준으로" 라고 적어 두었고, 그 문서가 말하는 앱은 "코드를 직접 수정하지
않는" 앱이다(지금 앱은 코드를 쓴다). **그래서 이 색인이 있다.**

읽는 법 세 줄:

1. **아래 「살아 있는 설계」 에 있는 폴더만 현재 설계의 SSOT 다.** 「역사」 의
   문서는 그 라운드가 끝난 날의 사진이다.
2. **코드가 문서를 이긴다.** 살아 있는 폴더 안에서도 "잠금 · 뒤집지 않는다" 로
   적힌 결정이 여러 번 뒤집혔다 — 그런 줄에는 인라인 정정 주석을 달아 두었다
   (형식 선례: `a2a/00-master-plan.md` 의 D4).
3. **진행 상태는 여기 없다.** 무엇이 끝났고 무엇이 남았는지는 `.oculpm/planner/*.md`
   가 갖는다. 이 폴더는 "왜 이 모양인가" 만 갖는다.

## 새 라운드를 시작할 때

`00-master-plan.md` 하나로 시작하고, 폴더 이름은 `YYYYMMDD_주제` 또는 기능
이름으로 짓는다. 그리고 **여기 표에 한 줄 추가한다** — 추가하지 않으면 다음
사람에게 그 폴더는 역사와 구별되지 않는다.

라운드가 끝나면 두 가지를 한다.

1. 설계와 다르게 간 자리를 **"구현 중 뒤집힌 결정"** 절에 적는다
   (`20260902_vscode-borrows/00-master-plan.md` 말미가 표본).
2. 폴더가 역사가 되면 마스터 문서 맨 위에 배너를 달고 이 색인의 표를 옮긴다.

> **아카이브** — 역사적 기록. 현재 코드의 SSOT 가 아니다.
