## 0. Executive Summary (한 페이지)

ocul-pm 의 정체성은 "에이전트가 일하는 동안 사용자는 **모니터링**한다"이다. 그런데 모니터링 표면이 전부 본 앱 창 안에 있다 — 앱을 열어야만 지금 무엇이 돌고 무엇이 쌓였는지 보인다. v2.2.0 훅 브리지가 세션 시작·종료의 **정확한 실시간 신호**를 확보했으므로, 이제 그 신호를 macOS 상단바로 끌어올린다.

컨셉은 두 제품의 합이다:

- **RunCat** — 아이콘 자체가 상태 표시기. 에이전트 세션이 활성일 때 아이콘이 움직인다 ("지금 에이전트가 일하고 있고 ocul-pm 이 기록 중").
- **Docker Desktop** — 클릭하면 팝오버가 반사적 질문에 5초 안에 답한다. ocul-pm 의 반사적 질문: **"지금 뭐가 돌고 있고, 오늘 뭐가 쌓였나."**

데이터는 전부 기존 서브시스템 재사용이다 — 콕핏의 프로젝트당 1콜 집계, 훅 인박스의 세션 신호, 플래너 파서, 스탠드업 생성기. 신규 백엔드 개념은 없고 트레이 요약 커맨드 1~2개 수준. 5 PR (PR-MB0~4).

## 1. 조사 팩트 시트 (2026-07-20 기준 — 구현 착수 시 실측 재검증 필수)

| 표면 | 확인된 사실 | 리스크/캐비앗 |
|---|---|---|
| **Tauri 2 트레이** | 내장 `TrayIcon` API (`tauri::tray`, feature `tray-icon`). 아이콘 교체·툴팁·클릭 이벤트(위치 좌표 포함) 지원 | 클릭 이벤트의 좌표계·멀티 모니터 동작은 **PR-MB0 실측** 대상 |
| **템플릿 이미지** | macOS 상단바 규약 — 모노크롬 + `is_template(true)` 로 라이트/다크 자동 대응 | 컬러 아이콘은 다크 메뉴바에서 깨짐 — 템플릿 강제 |
| **아이콘 애니메이션** | 트레이 아이콘의 주기적 프레임 교체로 구현 (RunCat 방식) | 타이머 주기·전력 영향 실측. **세션 활성 시에만** 애니메이션 (유휴 시 정지) |
| **팝오버 창** | 무장식(`decorations:false`) 보조 창 1개를 show/hide 재사용, 트레이 클릭 좌표 기준 배치. 포커스 이탈 시 hide | 진짜 NSPanel 동작(스페이스 넘나들기)은 서드파티(`tauri-nspanel`) 필요 — v1 은 기본 창으로, 부족하면 후속 검토 |
| **Dock 숨김** | `ActivationPolicy::Accessory` (macOS) — 런타임 전환 가능 | 창이 모두 숨은 상태에서만 의미. 설정 토글로 옵인 |
| **로그인 시 시작** | `tauri-plugin-autostart` 공식 플러그인 | 옵인 전용 — 기본 off |
| **창 닫기 → 상주** | `WindowEvent::CloseRequested` 를 prevent + hide 로 전환 가능 | 진짜 종료 경로(트레이 메뉴 "종료")를 반드시 제공 |

## 2. 목표 / 비목표

**목표**

1. 상단바 아이콘이 **에이전트 세션 상태를 실시간으로** 보여준다 (유휴/활성 애니메이션/주의 점).
2. 아이콘 클릭 팝오버가 앱을 열지 않고 **5초 안에** 답한다: 활성 세션 · 오늘 요약 · 최근 일지 · 활성 플랜 진행률.
3. 팝오버의 모든 항목은 클릭 시 **본 앱의 해당 화면으로 딥링크**된다 (팝오버는 모니터링 표면이지 미니 앱이 아니다).
4. 옵인 상주 모드: 창을 닫아도 메뉴바에 남고, 원하면 Dock 에서도 사라진다.

**비목표 (이번 라운드)**

- 팝오버에서의 편집·쓰기 작업 — 유일한 예외는 "스탠드업 복사" (백엔드만으로 동작, LLM 불필요).
- Windows/Linux 트레이 — macOS 를 레퍼런스로 먼저 (추상화는 Tauri 가 제공하므로 후속 확장 여지는 남긴다).
- 알림 센터 푸시(Notification) — 트레이 주의 점으로 충분, 푸시는 소음. 후속 검토.
- 메뉴바 전용 미니 차트/그래프 — v1 은 텍스트+글리프.

## 3. 아키텍처 결정 (D1~D5)

### D1 — 트레이 = Tauri 내장 TrayIcon, 템플릿 이미지 3상태 {#d1-tray-states}

- 상태: **유휴**(정적 모노크롬 로고) / **세션 활성**(동심원 펄스 프레임 교체 — 세션 수 무관 단일 애니메이션) / **주의**(정직성 감사 경고·파서 경고 존재 시 점 오버레이).
- 애니메이션 프레임은 번들 리소스로 사전 렌더 (런타임 드로잉 없음). 세션 0 이면 타이머 정지 — 유휴 전력 0.
- 옵션(설정): 아이콘 옆 텍스트로 오늘 일지 수 표시 (RunCat 의 CPU % 위치).

### D2 — 팝오버 = 무장식 보조 창 1개 재사용 {#d2-popover-window}

- 앱 기동 시 숨김 상태로 1회 생성, 트레이 클릭 시 클릭 좌표 기준 배치 후 show. 포커스 이탈·Esc·재클릭 시 hide.
- `alwaysOnTop` + `skipTaskbar` + `visibleOnAllWorkspaces`(가능 시). NSPanel 급 동작이 필요해지면 그때 `tauri-nspanel` 검토 (v1 비범위).
- 렌더는 기존 React 앱의 **경량 진입점** (트레이 전용 route) — 본 앱 번들을 통째로 로드하지 않고 트레이 요약 데이터만 그린다. 토큰(tokens.css)·테마는 공유.

### D3 — 데이터 = 기존 집계 재사용, 신규 커맨드 `tray_summary` 1개 {#d3-data-reuse}

- **세션**: 훅 인박스 → SessionActor 의 활성 세션 목록 (agent_label · 시작시각 · 프로젝트). 훅 미설치 프로젝트는 워처 휴리스틱 신호로 폴백 (기존과 동일한 신뢰 등급 표시).
- **오늘 요약·최근 일지**: 콕핏(StartScreen)이 쓰는 프로젝트당 1 list콜 버킷팅 로직 재사용.
- **플랜 진행률**: 플래너 파서의 활성 플랜 done/total (MCP `plan_status` 와 동일 소스).
- 커맨드는 `tray_summary(project_ids)` 하나로 집약 — 팝오버 열릴 때만 호출 (폴링 없음). 트레이 아이콘 상태는 세션 이벤트 push 로 갱신.

### D4 — 상주·Dock = 전부 옵인, 기본은 현행 유지 {#d4-optin-residency}

- 설정 → 일반에 토글 3개: ① 메뉴바 아이콘 표시 (기본 **on**, 팝오버는 항상 사용 가능) ② 창 닫기 = 메뉴바로 최소화 (기본 off) ③ Dock 아이콘 숨김 (기본 off, ②가 on 일 때만 활성).
- 트레이 우클릭(또는 팝오버 하단) 메뉴에 "Ocul-PM 종료" 상시 제공 — 상주 모드에서 프로세스를 못 죽이는 상황 금지.

### D5 — 팝오버 = 읽기 전용 + 딥링크, 쓰기는 스탠드업 복사뿐 {#d5-readonly}

- 모든 행은 클릭 시 본 앱 focus + `uiV2View`/항목 핸드오프로 이동 (기존 navRegistry·WorkspaceContext 경로 재사용, 새 라우팅 개념 없음).
- 빈 상태 설계: 세션 0·일지 0 이면 "오늘 아직 기록 없음 · 마지막 활동 {시각}" — 침묵도 정보다.

## 5. 보안·리소스 불변식

1. 팝오버·트레이는 **네트워크 호출 없음** — 전부 로컬 집계 (스탠드업 복사도 백엔드 로컬 생성 경로만).
2. 유휴 시 추가 CPU ~0 (애니메이션 타이머는 세션 활성 시에만), 폴링 없음 (팝오버 열릴 때만 조회).
3. 트레이 텍스트·팝오버에 일지 **제목**까지만 — 본문·diff 는 절대 노출하지 않는다 (어깨너머 노출 면적 최소화).
4. 상주·Dock 숨김·autostart 는 전부 옵인, 기본값은 현행 동작 유지.

## 6. 성공 기준 (제품 관점)

- 앱 창이 닫혀 있어도 상단바만 보고 "지금 에이전트가 일하는 중인지" 안다.
- 팝오버를 연 뒤 5초 안에 오늘의 상태(세션·일지·경고)를 파악하고 닫는다 — 본 앱을 여는 것은 선택이 된다.
- 상주 모드를 켠 사용자의 일상 흐름: 아침에 팝오버로 어제 요약 확인 → 스탠드업 복사 → 하루 종일 아이콘만 곁눈질.
