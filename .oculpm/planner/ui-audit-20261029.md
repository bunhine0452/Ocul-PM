사용자 판정(10-29) 「UI가 전혀 심플하지 않고 사용자를 고려하지 않았어」에 대한 검사서 claude.ai/artifact/4rB4PAGWvy4gqTtCTRwZHW 의 고치는 순서 1~7. 새 화면·새 기능 없음 — 있는 것을 고치고 덜어낸다.

**완료 조건:** 검사서의 순서 1~7 이 main 에 들어가, 같은 하네스(일지 48건)로 찍은 오늘 첫 장의 버튼 4개 이하·딱지 3개 이하, 화면에 보이는 합계가 전부 맞고, 12px 이하 글자 토큰 비율이 40% 아래이며, 옛 용어(증거·판정·확인함·사용자 몫)와 줄표 이은 문장이 i18n 게이트에 걸린다
**확인 명령:** pnpm typecheck && pnpm test && pnpm lint && pnpm build

## 말 — 단어표 · 줄표 · 사람이 주어 {#words}
- [ ] 단어표 적용 — 검사 · 완료 검사(통과/실패) · 읽음 · 먼저 볼 것 · 내 차례 · 일지 없는 변경 · 실행 중 · 이력 (ko.ts · en.ts) {#glossary}
- [ ] 줄표(—)로 두 문장을 이은 한국어 문구 정리 — 한 문장 한 뜻, 같은 말 두 번 금지 {#em-dash}
- [ ] i18n 게이트에 옛 용어와 줄표 이은 문장 금지 추가 {#words-gate}

## 숫자 규칙 — 한 숫자 한 단위, 합은 맞게, 0 은 안 씀 {#numbers}
- [ ] 오늘 한 일 합계를 맞추고 「나머지 N건은 접었어요」를 걷는다 {#today-sum}
- [ ] 계획 완료 검사는 한 줄 한 상태 — 「명령 없음」과 「실패」를 같이 말하지 않는다 {#plan-verdict}
- [ ] 0 인 수를 쓰지 않는다 (갱신 기록 0줄 · 결정 0 등) {#hide-zero}

## 오늘 — 먼저 볼 것 / 검사 없는 일지 / 다음 할 일 {#today}
- [ ] 먼저 볼 것에는 실패·막힘·일지 없는 변경·플러그인만, 검사 없는 일지는 한 묶음에 읽음 버튼 하나 {#today-split}
- [ ] 내 차례(계획의 사람 항목)는 오늘 목록에서 빼고 한 줄 링크로 {#today-mine}
- [ ] 반복 메타(에이전트 이름 · 같은 이유 문장) 걷기 — 다를 때만 {#today-repeat}

## 작업 일지 — 본문 먼저, 두 줄 제목 {#journal}
- [ ] 상세는 변경 요약 → 검사 → 바뀐 파일 순, 「전체 본문」 접기와 중복 제거 {#journal-body}
- [ ] 목록 제목 두 줄 · 에이전트 하나면 이름 생략 · ✓ 대신 예외만 글자로 {#journal-list}
- [ ] 종류 고르기와 「검사 없는 것만」 을 나눠 같이 걸 수 있게 {#journal-filter}

## 글자 · 회색 · 초록 {#tokens}
