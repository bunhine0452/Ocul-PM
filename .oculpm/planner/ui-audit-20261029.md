사용자 판정(10-29) 「UI가 전혀 심플하지 않고 사용자를 고려하지 않았어」에 대한 검사서 claude.ai/artifact/4rB4PAGWvy4gqTtCTRwZHW 의 고치는 순서 1~7. 새 화면·새 기능 없음 — 있는 것을 고치고 덜어낸다.

**완료 조건:** 검사서의 순서 1~7 이 main 에 들어가, 같은 하네스(일지 48건)로 찍은 오늘 첫 장의 버튼 4개 이하·딱지 3개 이하, 화면에 보이는 합계가 전부 맞고, 12px 아래 글자가 없고(배지 · 단축키만 예외) 보조 회색이 한 단이며, 옛 용어(증거·판정·확인함·사용자 몫)와 줄표 이은 문장이 i18n 게이트에 걸린다
**확인 명령:** pnpm typecheck && pnpm test && pnpm lint && pnpm build

## 말 — 단어표 · 줄표 · 사람이 주어 {#words}
- [x] 단어표 적용 — 검사 · 완료 검사(통과/실패) · 읽음 · 먼저 볼 것 · 내 차례 · 일지 없는 변경 · 실행 중 · 이력 (ko.ts · en.ts) {#glossary}
- [x] 줄표(—)로 두 문장을 이은 한국어 문구 정리 — 한 문장 한 뜻, 같은 말 두 번 금지 {#em-dash}
- [x] i18n 게이트에 옛 용어와 줄표 이은 문장 금지 추가 {#words-gate}

## 숫자 규칙 — 한 숫자 한 단위, 합은 맞게, 0 은 안 씀 {#numbers}
- [x] 오늘 한 일 합계를 맞추고 「나머지 N건은 접었어요」를 걷는다 {#today-sum}
- [x] 계획 완료 검사는 한 줄 한 상태 — 「명령 없음」과 「실패」를 같이 말하지 않는다 {#plan-verdict}
- [x] 0 인 수를 쓰지 않는다 (갱신 기록 0줄 · 결정 0 등) {#hide-zero}

## 오늘 — 먼저 볼 것 / 검사 없는 일지 / 다음 할 일 {#today}
- [x] 먼저 볼 것에는 실패·막힘·일지 없는 변경·플러그인만, 검사 없는 일지는 한 묶음에 읽음 버튼 하나 {#today-split}
- [x] 내 차례(계획의 사람 항목)는 오늘 목록에서 빼고 한 줄 링크로 {#today-mine}
- [x] 반복 메타(에이전트 이름 · 같은 이유 문장) 걷기 — 다를 때만 {#today-repeat}

## 작업 일지 — 본문 먼저, 두 줄 제목 {#journal}
- [x] 상세는 변경 요약 → 검사 → 바뀐 파일 순, 「전체 본문」 접기와 중복 제거 {#journal-body}
- [x] 목록 제목 두 줄 · 에이전트 하나면 이름 생략 · ✓ 대신 예외만 글자로 {#journal-list}
- [x] 종류 고르기와 「검사 없는 것만」 을 나눠 같이 걸 수 있게 {#journal-filter}

## 글자 · 회색 · 초록 {#tokens}
- [ ] 12px 아래 글자 0 — 배지 · 단축키(kbd)만 예외, 본문 13 · 보조 12 (디자인 게이트) {#type-floor}
- [ ] 보조 회색 한 단으로 합치기 (text-2/text-3 대비 실측) {#grey-one}
- [ ] 초록은 주 버튼과 통과에만 — 내 차례는 중립 딱지, 주 버튼 바탕 accent-strong {#green-meaning}

- [ ] 계획 — 끝난 단계 한 줄 접기, 항목 제목 줄바꿈, 다음 칸 문장 {#plan-head}
- [ ] 변경 — 파일 행 한 줄(M/A/D), 기록 요청을 터미널로, 고정 안내문 걷기 {#diff-rows}
- [ ] 터미널 — 세션 하나면 칸 없음, 둘 이상이면 위 탭 줄 {#term-col}
- [x] 터미널 — 실행 중인 세션이 있는 창을 닫거나 앱을 끌 때 묻기 (지금은 묻지 않고 함께 끝난다) {#term-close-guard}
- [x] 터미널 — 프로젝트 전환 목록 · 시작 창에 프로젝트별 실행 중 세션 표시 (다른 창의 세션이 안 보인다) {#term-running-badge}
- [ ] 빈 화면 한 모양 — 왼쪽 정렬, 문장 하나, 버튼 하나 {#empty-one}
