발표 세 건(Lauren Tan 「All Code Is Slop」 · Simon Willison 「2026 in LLMs」 · Lydia Hallie 「Rethinking Claude Code Best Practices」)이 말하는 것: 사람은 diff 대신 결정적 검사와 증거를 보고, 승인은 자동 모드가, 확인은 훅이 맡는다. 그 흐름에서 Ocul 이 아직 사람이 터미널 앞에 있다고 가정한 자리를 고친다. 사용자 지시 11-22: 「병목이 되지 않도록 업그레이드 · UI 는 병렬 세션으로 · 배포까지」.

**완료 조건:** Windows 에서 플러그인의 MCP 도구가 붙고, 앱이 없는 클라우드 세션도 일지 없이 조용히 끝나지 않으며, 항목을 닫고도 확인 명령을 안 돌린 대화가 한 번 짚이고, pull · clone 으로 받기만 한 파일이 「통과 뒤 바뀜」으로 서지 않고, 자동 모드가 막은 행동과 새 기다림 알림이 오늘에 서며, 병렬 세션의 UI 개선이 합류해 v4.12.0 으로 나간다
**확인 명령:** pnpm typecheck && pnpm test && pnpm lint && pnpm build && cd src-tauri && cargo test --locked
