사용자 결정(10-29): 이동은 화면·프로젝트 둘 다, 이름은 보이는 것만 Ocul, 주고받기는 넷 다(묻고 답하기 · 기다림 알림 · 보내기 · /goal), 튜토리얼은 첫 실행 모달 + 다시 보기. Orca(stablyai/orca, MIT)에서 가져올 것 포함.

**완료 조건:** 앱이 보이는 이름 Ocul 로 나가고(식별자 유지), 윗줄에 가지 않고도 화면과 프로젝트를 오가며, 첫 실행 모달이 시작 창 세 단계를 대신하고, 앱 안 터미널의 Claude 상태(실행 중 · 기다림 · 끝남)가 프로젝트 목록과 오늘에 보이며, Claude 의 질문에 앱에서 답하고 앱에서 Claude 에게 보낼 수 있다
**확인 명령:** pnpm typecheck && pnpm test && pnpm lint && pnpm build && cd src-tauri && cargo test --locked

## Claude 와 주고받기 {#talk}
- [x] 앱 안 터미널이 OSC 7501(Program Status Protocol)을 받아 세션 상태(실행 중 · 기다림 · 끝남 · 오류)를 안다 — Orca 의 파서·탐침 응답(MIT) 이식 {#osc7501}
- [x] 플러그인 훅 Notification(permission_prompt · idle_prompt)으로 바깥 터미널 세션의 기다림도 안다 — 훅이 이기고 OSC 가 빈자리를 채운다 {#notify-hook}
- [x] 「Claude 가 기다려요」 — 오늘 먼저 볼 것 · 프로젝트 목록 · macOS 알림(그 창이 앞에 있으면 알림 안 함) {#waiting-alert}
- [ ] MCP 도구 ask_user + 오늘의 답 칸 — 답은 앱 안 세션이면 터미널에 입력, 바깥 세션이면 다음 훅이 싣는다 {#ask-user}
- [x] 일지 · 계획 항목 · 변경 파일에서 「Claude 에게 보내기」 — 그 맥락을 붙여 지금 도는 앱 안 세션에 {#send-to-claude}
- [x] 계획의 「끝까지」를 /goal <완료 조건 + 확인 명령> 으로 — 앱 안 터미널에 입력(claude "/goal …" 시작 인자는 문서에 없어 실측) {#goal}
- [x] 「터미널에서 실행」 뒤 claude 가 없으면(command not found) 실행 중으로 세지 않고 알려 준다 — Orca agent-turn-idle-verdict 참고 {#launch-fail}
- [>] Claude Code 채널(연구 미리보기)로 바깥 세션에도 바로 전달 — 우리 플러그인은 허용 목록 밖이라 매번 확인창이 뜨므로 보류 {#channels-later}
