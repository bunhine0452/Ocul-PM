사용자 결정(10-29): 10-28 에 걷은 앱 안 터미널을 새 디자인으로 다시 들인다. 옛 구현(PTY 호스트 · 떼어낸 창 · 셸 통합, 6만여 줄 · 10월 fix 1위)은 되살리지 않고, 앱 안 세션 + 검증된 한글 입력 브리지만. 범위 동결의 「대신 걷을 표면」 = 오늘·계획 「다음」 의 클립보드 프롬프트 복사 → 「터미널에서 실행」.

**완료 조건:** 윗줄 「터미널」 탭에서 Claude Code 를 한글 입력으로 돌릴 수 있고, 오늘·계획의 「다음」 이 그 터미널에서 바로 실행되며(클립보드 복사 경로는 걷음), 세션은 창·앱이 닫히면 함께 정리되고, 게이트·E2E(Windows·Linux)가 초록으로 main 에 들어간다
**확인 명령:** pnpm typecheck && pnpm test && pnpm lint && pnpm build && (cd src-tauri && cargo test --locked)

## 설계 {#design}
- [x] 터미널 = 윗줄 다섯째 탭(⌘5) — 왼쪽 세션 목록 한 칸 + 터미널. 떼어내기·도크·PTY 호스트·셸 rc 통합 없음, 세션은 앱 안(앱이 꺼지면 끝) {#design-tab}
- [x] 걷을 표면 — 오늘 「다음」 · 계획 「다음/끝까지」 의 클립보드 복사를 「터미널에서 실행」 으로 바꾸고 복사 경로는 지운다 {#design-retire}

## 백엔드 — 앱 안 PTY {#backend}
- [x] portable-pty 세션: term_open(프로젝트 루트, 셸 또는 명령) · term_write · term_resize · term_close · term_list, 출력은 Channel {#be-session}
- [x] 창이 닫히면 그 창의 세션, 앱이 끝나면 전부 죽인다 — 고아 프로세스 0 {#be-lifecycle}
- [x] egress_spawn_ledger 에 셸 실행 자리 분류(네트워크 가능 — 사용자의 셸) · CLAUDE_CODE_NO_FLICKER=1 {#be-ledgers}
- [x] 왕복(echo) · 크기 바꾸기 · 닫으면 자식이 죽는다 테스트 {#be-tests}

## 화면 {#screen}
- [x] 터미널 탭: 세션 목록(이름 · 도는 중/끝남 · 시작 뒤 일지 수) + xterm, 새 세션 ⌘T · 닫기 {#sc-tab}
- [x] 한글 입력 브리지 되살리기(imeBridge — WKWebView 조합 이벤트 없음 · 낱자 중복 · NBSP) {#sc-ime}
- [x] 토큰 색 · 밝게/어둡게 · 링크는 기본 브라우저 · 크롬은 작게 {#sc-theme}

## 기록 고리 {#loop}
- [x] 오늘 「다음」 · 계획 「다음/끝까지」 → 새 세션에서 claude "<프롬프트>" 실행, 클립보드 경로 삭제 {#loop-run}
- [x] 세션 줄에 「시작 뒤 일지 n · 마지막 판정」 — 터미널에서 기록으로 한 번에 {#loop-records}

- [x] CLAUDE.md 범위 동결 줄 · CHANGELOG v4.0.0 · README · 랜딩 · 위키를 터미널 복귀 사실로 {#ship-docs}
